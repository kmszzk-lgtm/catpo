# 첫 버전 (MVP) 범위

## 목표

"나가서 모으고, 돌아와서 버티는" 핵심 재미가 실제로 재미있는지 가장 빨리 확인한다. 기획 전체를 버리는 것이 아니라, 나머지는 첫 버전이 돌아간 뒤에 차례로 붙인다.

## 3단계 시험판 (2026-11-08)

그림 없이 글자와 버튼만 있는 화면이다. 흐름이 재미있는지 먼저 눌러 보고, 그림은 뒤에 붙인다.

- ▶(Play)를 누르면 장면 설정 없이 저절로 뜬다.
- 캐릭터 고르기: 고른 캐릭터는 직접 맡고(★), 나머지 셋은 AI가 맡는다.
- 옥탑방 화면: 위에 시각·날씨·외출 가능 시간·집 정화·현관, 왼쪽에 4명 상태, 가운데에 장소별 할 일, 오른쪽에 공용 창고, 아래에 일어난 일 글.
- 장소 버튼(아래층 아이콘 대신): 옥상(빗물받이, 파견, 자동 파견), 옥탑방(물 끓이기, 먹기·마시기, 함께 놀기), 3층(정화제, 몸·집 정화), 2층(아직 없음), 1층(현관 보수), 지하(바이오쿨러 그림 자리).
- 시간: 게임 1시간 = 실제 3분 (제안). 시간을 빠르게 하는 기능은 없다 (확정, 처음 시험판에 있던 배속 버튼은 뺌). "모두 잠자기"로 아침까지 넘긴다.
- 기획자 확인 (2026-11-08): 잘 작동함. 다만 모든 UI를 한 화면에 담은 것은 작동 확인용이고, 옥상과 옥탑방을 한 화면 탑뷰로, 이지 모드를 생각해서 [화면 배치](16-ui-layout.md)를 다시 짜기로 함.
- 일하는 중 (제안): 집 안 일은 결과가 바로 나오고, 그 사람은 걸리는 시간 동안 다른 일을 못 한다. 자동 파견도 일을 마친 뒤에 나간다.
- 직접 밖에 나가기는 4단계에서 만든다.

## 2단계에서 만든 것

- 배고픔·목마름 (감염도가 높으면 빨리 옴, 길냥이는 덜 옴, 길냥이는 충동적으로 더 먹음)
- 오염도·감염도가 스트레스를 늘리는 규칙 (Q87)
- 숙련도와 경험치 (집 안 경험치와 외부 경험치에 특성 배율)
- 정화제 제작, 몸 정화, 집 정화
- 물 끓이기, 모닥불 연료(종이·나무), 가스버너와 부탄가스(닳고 고장 남)
- 빗물받이와 비 오는 날
- 현관 보수, 집 안 가구를 부숴 자재 만들기, 현관이 뚫리면 게임 오버
- 바깥 필드(북쪽 편의점 두 곳·공구점 등), 직접 수색, 고갈
- AI 파견: 방향 차지, 해 지기 전 귀환(길냥이는 1시간 일찍), 가까운 오브젝트 제거와 잔해물

## Unity 확인

- Unity 상단 메뉴 **좀비냥 > 규칙 코드 확인**을 누르면, 튜토리얼 반나절을 돌려 보고 Console 창에 결과를 찍는다.
- 클라우드에서는 Unity 대신 흉내 낸 코드로 컴파일과 실행만 확인한다 (`tests/UnityCompileCheck`).
- **2026-11-08 기획자 PC의 Unity 6.6에서 확인 완료.** 컴파일되고 메뉴가 끝까지 돌았다. 처음에는 에디터 메뉴가 규칙 코드의 internal 멤버를 써서 Safe Mode 창이 떴고, 고친 뒤 통과했다.
- 처음 열 때 Unity가 기본 패키지(Test Framework, Custom NUnit, Visual Studio Editor, JetBrains Rider Editor)를 만들었다. 화면용 Unity UI 패키지는 아직 없다.

## 아직 안 한 것

- 시간 초과 때의 자동 귀환·직접 귀환 선택 (규칙은 기획에 있음)
- 부상과 치료, 체력, 굶주림으로 인한 피해
- 특성 선택(집냥이의 추가 특성)과 포인트
- 바이오쿨러와 음식 부패, 서적
- 저장과 불러오기
- Unity 화면 (3단계부터)
