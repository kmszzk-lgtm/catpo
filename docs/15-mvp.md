# 첫 버전 (MVP) 범위

## 목표

"나가서 모으고, 돌아와서 버티는" 핵심 재미가 실제로 재미있는지 가장 빨리 확인한다. 기획 전체를 버리는 것이 아니라, 나머지는 첫 버전이 돌아간 뒤에 차례로 붙인다.

## 넣는 것 (확정, 2026-11-08)

| 분야 | 첫 버전에 넣는 것 |
|---|---|
| 모드 | 혼자 하는 **튜토리얼 모드** |
| 기간 | **봄 한 계절** (30일) |
| 집 밖 | 집 근처 **한 방향**부터. 편의점 두 곳과 공구점 |
| 캐릭터 | 집냥이, 군냥이, 의냥이, 길냥이와 고유 특성 |
| 몸 상태 | 오염도와 감염도, 정화제 |
| 집안일 | 빗물받이, 옥탑방 모닥불(요리·물 끓이기), 현관 보수 |
| 그 밖에 | AI 파견, 공용 창고, 무게 제한, 스트레스, 잠자기 |
