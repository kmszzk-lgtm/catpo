## 진행 상태 (2026-11-07)

- **확정**: 제목(좀비냥), 세계관(목성시, 고양이화 바이러스, 감염 단계), 옥탑방 주택 거점과 도르래, 캐릭터 4명과 고유 특성(길냥이 = 도둑), 운용 규칙(혼자면 1명 + AI 3명, 집냥이 사망 시 월드 종료), 특성 선택과 해금, 튜토리얼 흐름, 시간과 계절(1년 약 100시간), 잠자기, 스트레스, 외출 규칙, AI 파견, 귀환 규칙, 엔진(Unity)
- **미정**: 시계 속도(제안: 게임 1시간 = 실제 약 3분), 하루 여러 번 외출, 의냥이·길냥이 합류 장면, 제작 취향, 시점, 게임 목표, 습격 방식
- 설계 순서: 게임 시작부터 플레이어가 겪는 순서대로 다듬는 중. 게임 시작과 캐릭터는 거의 정리됨. 다음은 **집안일 튜토리얼과 첫 외출**
