# 기획 문서

대화가 끊겨도 이 폴더만 읽으면 이어서 작업할 수 있도록, 정해진 내용은 모두 여기에 남깁니다.

## 표기 규칙

| 표기 | 뜻 |
|---|---|
| **확정** | 기획자가 직접 정한 내용 |
| **제안** | 논의 중 나온 추천. 기획자 확인 전까지 바뀔 수 있음 |
| **미정** | 아직 정하지 않음. [미정 사항](open-questions.md)에 질문으로 정리 |
