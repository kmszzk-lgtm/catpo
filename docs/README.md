# 기획 문서

좀비 아포칼립스 생존 모바일 게임 **좀비냥**(코드명 `catpo`)의 기획 문서 모음입니다.
대화가 끊겨도 이 폴더만 읽으면 이어서 작업할 수 있도록, 정해진 내용은 모두 여기에 남깁니다.

## 표기 규칙

| 표기 | 뜻 |
|---|---|
| **확정** | 기획자가 직접 정한 내용 |
| **제안** | 논의 중 나온 추천. 기획자 확인 전까지 바뀔 수 있음 |
| **미정** | 아직 정하지 않음. [미정 사항](open-questions.md)에 질문으로 정리 |

## 진행 상태 (2026-11-08)

- **확정**: 제목(좀비냥), 세계관(목성시, 고양이화 바이러스), 옥탑방 주택 거점(사거리, 도르래), 집 공간, 캐릭터 4명과 고유 특성, 운용 규칙(방장 결정), 프롤로그(튜토리얼만), 시간과 계절, 잠자기, 스트레스, 오염도와 감염도(지역 보스 추가 오염 포함), 집안일, 정화제, 습격 없음과 봉쇄, 공용 창고, 조작과 퀵슬롯, 시점(탑다운), 집 밖(4방향, 화성시청 주변 지도, 무게, 고갈, 차량 없음, 총기 출처), 외출 전 유인, 분해·결합과 서적, AI 파견, 난이도(튜토리얼 → 이지, 노멀·하드 보류), 특성 배분, 특전 해금, 합류 요청, 유니크 캐릭터·스킨·결제, 튜토리얼 엔딩과 첫 지역 보스, 지역 안정화, 거점 이전, 연합과 AI팀(이지), **첫 버전 범위**, 엔진(Unity)
- **미정**: 집냥이 집안 활동 스트레스 감소량(Q99), 우호도·공물(Q83, Q84), 첫 AI팀 이름(Q85), 지도 데이터(Q65), 도전 콘텐츠(나중에), 시계 속도(제안: 게임 1시간 = 실제 약 3분)
- **지금 단계: 첫 버전 개발.** 규칙 코드 1·2단계 완료 (테스트 112개). 기획자 PC의 Unity 6.6에서 "좀비냥 > 규칙 코드 확인" 통과 (2026-11-08). 다음은 3단계 Unity 화면 ([첫 버전 범위](15-mvp.md))
