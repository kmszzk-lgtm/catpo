# 집안일과 생활

## 기본 조건 (확정)

- **전기는 복구할 수 없다.** 발전기 같은 것도 없다.
- **집 안에서는 오염도가 오르지 않는다.** 의냥이가 정화 작업을 마쳤기 때문이다.

## 집 공간 (확정)

- 직접 돌아다니는 곳은 **옥탑방과 옥상뿐**이다.
- 그 아래층(3층, 2층, 1층, 지하)은 **이미지로만 존재**하고 직접 방문하지 않는다.
- 아래층의 설비는 **아이콘을 터치해서** 넣고 조작한다.

## 물 (확정)

- 옥상에 **빗물받이**를 설치한다. 비닐, 방수포 등을 플라스틱 용기와 결합하는 방식이다.
- **물 끓이기는 요리에 포함된다.**

### 제안

- 빗물은 끓여야 마실 수 있다. 생수는 수색으로 구한다.
- 비 오는 날이 있어야 빗물이 모인다. 계절마다 비 오는 날 수를 다르게 한다.

## 불과 요리 (확정)

- 기본은 **옥탑방에서 모닥불**을 피우는 것이다. 바람막이와 환기가 되게 해 둔다.
- 나무, 종이처럼 **탈 것을 계속 가져와야** 한다.
- **가스버너**도 있다. 하지만 가정집에 부탄가스가 많이 있는 경우는 없다.
  - 부탄가스를 가져오면 **효율 좋게 오래** 요리할 수 있다.
  - 부탄가스만 닳는 것이 아니라 **가스버너도 고장 날 수 있다.** 그래서 가스버너를 통째로 파밍해 오는 것도 좋다.

| 조리 도구 | 연료 | 장점 | 단점 |
|---|---|---|---|
| 모닥불 | 나무, 종이 등 | 기본. 언제든 쓸 수 있음 | 연료를 계속 구해 와야 함 |
| 가스버너 | 부탄가스 | 효율이 좋고 오래 감 | 부탄가스가 귀함. 버너가 고장 남 |

## 텃밭 (확정)

- **옥상 텃밭**. 농사는 캐주얼하게 간다.
- **생산량은 많지 않다.** 많으면 파밍하는 재미가 없어지기 때문이다.
- 식품으로서의 기능은 어느 정도 한다.
- **업적 해금용**으로 쓴다.

### 제안

- 작물은 계절을 탄다. 겨울에는 키울 수 없다.
- 물은 빗물을 쓴다. 물을 텃밭에 줄지 마실지 고민하게 만든다.

## 바이오쿨러 (확정)

- **지하 1층**, 집냥이가 살던 지하실에 있는 냉장고다.
- 설치 기사가 **숯과 소형 벤틸레이터**로 자동 유지보수되게 해 놨고, 집냥이는 **물만 잘 주면 된다**고 설명을 들었다. 실제로 멀쩡하게 유지된다.
- 집냥이는 식물이 뭔지도, 어떤 원리인지도 모르고, 물만 주면서 냉장고로 쓰고 있다.
- **용량이 적다.**
- 설치 기사가 **지하실에서만 정상 작동**하게 설치해 둔 셈이다. 지하 1층에서 꺼내면 습도 제어가 안 돼서 어차피 쓸 수 없다.
- 그래서 **지하실을 봉쇄하면 바이오쿨러도 잃는다.**
- 화면에는 이미지로만 있고, 아이콘으로 조작한다 (물 주기, 음식 넣고 빼기).

## 현관과 정화 (확정)

- **1층 현관이 뚫리지 않게 유지보수하는 것이 핵심**이다.
- 바깥에서 계속 충격이 온다. 그래서 외부에서 파밍해 온 온갖 가구로 **1층 현관부터 2층 계단까지** 채운다.
- 2층, 3층에 있는 가구도 끄집어내서 계속 던지고, 막고, 테이프를 감는다.
- 집 안의 가구를 부숴 **자재**로 만들어서 막는다. 집 안 가구만으로는 부족해서 밖에서도 가져와야 한다.
- **현관이 뚫리면 게임 오버**다.

## 정화제 (확정)

- 소독약, 락스, 술(알코올) 같은 **재료**로 정화제를 **제작**한다. 재료를 그대로 쓰는 것이 아니다.
- 의냥이만 만들 수 있는 것은 아니다. **의료 레벨이 높으면** 누구나 만들 수 있다.
- 정화제는 **오염도만** 낮춘다. 감염도에는 듣지 않는다.
- 정화제는 두 군데에 쓰인다.
  - **집 정화**: 집 안 오염도가 오르지 않게 유지한다. 현관이 조금이라도 뚫리면 바이러스가 올라와서 훨씬 많이 든다.
  - **몸 정화**: 외출하고 돌아온 캐릭터의 전신을 소독하고 항생제를 먹여 오염도를 낮춘다 ([오염도](03-infection.md#오염도-확정)).

### 제안

- 재료는 마트(락스, 술), 약국·병원(소독약)에서 구한다.
- 몸 정화 1회에 오염도 -20. 정화제는 소모품이라 누가 써 줘도 효과가 같다 (확정).

### 제안

- 현관에 **내구도**를 둔다. 바깥 충격으로 매일 조금씩 줄고, 가구·판자·테이프로 보수한다.
- 가구째로는 도르래로 올리기 힘들어서 분해한 나무 판·나무 막대로 가져온다 (확정). 그래도 무게가 있어서 도르래 업그레이드와 연결된다.

## 지하실 봉쇄 이벤트 (확정)

**가을 중 어느 날 무작위로** 일어난다. (가을은 61~90일. 처음에는 100일 무렵으로 정했다가 바꿈)

1. 현관문이 조금 뚫린다. 군냥이가 **날을 세운 긴 나무 막대**로 좀비냥들을 죽였다는 이벤트가 나온다.
2. 의냥이가 말한다. 확실하게 봉쇄하지 않으면 바이러스가 계속 올라와서, 정화에 쓰는 약품이 감당이 안 될 거라고.
3. 계단으로 올라오는 길을 가구, 나무, 돌 같은 온갖 것으로 막고, **방수포·테이프·비닐로 계단과 통로를 아예 밀봉**한다. **아래층이 봉쇄**되어 지하실과 바이오쿨러를 잃는다.

- 그전까지는 **1층 현관만** 막아 둔 상태다. 밤에 주기적으로 오는 습격은 없다.
- 새 해가 오기 직전에는 거대 호랑이 좀비냥이 이 바리케이드를 다 파헤치고 계단을 뚫고 올라온다 ([엔딩과 거점 이전](13-endings-and-relocation.md#거대-호랑이-좀비냥-확정)).

- **현관 보수를 제때 안 하면 가을 전에 더 일찍 일어날 수 있다.** 이때도 어차피 위험하므로 **선택지 없이 즉시 봉쇄**한다. (처음엔 "즉시 봉쇄 / 약품을 더 가져와 버티기" 선택지를 두려 했다가 없앰)

| 발생 | 진행 |
|---|---|
| 가을 중 무작위 | 즉시 봉쇄 |
| 현관 보수를 소홀히 해서 가을 전에 | 즉시 봉쇄 |

### 미정

- 현관 내구도와 보수 재료의 수치 ([Q45](open-questions.md))

## 시작 살림 (확정)

1층 현관 앞 **경비실에 도어락 마스터 키**가 있어서, 지하부터 옥상까지 집을 다 열어 살림을 모아 두었다.

| 물자 | 양 | 상태 |
|---|---|---|
| 생수 | 6통 (집에 많이 두지 않음) | **확정** |
| 보존식 (통조림, 라면, 초콜릿) | 1인 기준 30일치. 4명이면 일주일이면 다 먹음 | **확정**. 배분은 제안: 통조림 10, 라면 12, 초콜릿 8 |
| 조미료 (소금, 간장, 참기름, 식용유, 카놀라유) | 많아도 됨. 집집마다 한 통씩 | **확정**. 각 4통은 제안 |
| 침대, 매트리스, 테이블 같은 가구 | 집집마다 많음. 분해하면 나무 판과 나무 막대 | **확정**. 24개는 제안 |
| 부탄가스 | 5개 | **확정** |
| 가스버너 | 1개 (설치됨) | **확정** |
| 비닐봉투 | 어지간한 집에 다 있음 | **확정**. 20개는 제안 |
| 페트병(1.5L), 냄비 | 빗물 담는 용기 | **확정**. 페트병 4, 냄비 3은 제안 |
| 종이, 나무 막대, 나무 판, 테이프, 락스, 술병, 소독약 | | 제안: 종이 20, 막대 4, 판 2, 테이프 3, 락스 4, 술병 3, 소독약 2 |
| 의냥이의 의료품 | 응급처치 도구, 상비약, 진통제 | **확정**. 개수는 제안 |

## 첫 버전 코드의 수치

| 항목 | 내용 | 상태 |
|---|---|---|
| 불 고르기 | 요리할 때 모닥불과 가스버너 중 **플레이어가 고른다** | **확정** |
| 가스버너 수명 | 부탄가스 **100통** 정도 쓰면 고장 | **확정** |
| 나무 | **나무 막대**와 **나무 판** 두 가지 | **확정** |
| 모닥불 연료 | 종이 1개 = 요리 1번, 나무 막대 1개 = 1번, 나무 판 1개 = 2번. 종이, 막대, 판 순으로 태움 | 제안 |
| 요리 시간 | 모닥불 1시간, 가스버너 30분 | 제안 |
| 부탄가스 | 1통 = 요리 6번 | 제안 |
| 빗물받이 | **비닐봉투 + 나무 막대 + 담을 수 있는 용기**(1.5L 페트병, 냄비). 냄비는 **그냥 비 오는 곳에 둬도 됨** | **확정** |
| 빗물 양 | 비 오는 날 비닐봉투 빗물받이 하나당 4개, 냄비만 두면 2개 | 제안 |
| 비 오는 날 | 봄 30%, 여름 45%, 가을 25%, 겨울 10% | 제안 |
| 빗물 | 끓여야 마실 수 있음. 빗물 2개 → 끓인 물 2개 | 제안 |
| 현관 보수 | 가구를 분해한 **나무 판·나무 막대**로 보수 (가구째로는 도르래로 올리기 힘듦) | **확정** |
| 현관 수치 | 매일 4씩 상함. 나무 판 +15, 나무 막대 +5, 테이프 +5 | 제안 |
| 가구 분해 | 가구 1개 → 나무 판 1 + 나무 막대 2. 집 안 가구가 바닥나면 "밖에서도 가져와야 한다" 메시지 | 제안 |
| 정화제 제작 | 의료 레벨 3 이상이나 의냥이. 소독약 1 → 2개, 락스 1 + 끓인 물 1 → 2개, 술병 1 → 1개 | 제안 |
| 제작 실력 | 만드는 사람의 레벨과 특성이 **제작 속도와 재료 절감**에 영향 | **확정** |
| 제작 실력 수치 | 속도 = 1 + (레벨-1) × 0.1 (의료 제작은 전문의 1.5배). 재료 절감은 (레벨-1) × 0.05씩 쌓여 1이 되면 재료 1개를 아낌 | 제안 |
| 몸 정화 | 정화제 1개로 오염도 -20, **누가 해 줘도 같음** | **확정** (수치는 제안) |
| 집 정화 | **매일** 정화제를 써야 함. 끊기면 집 안에서도 **바깥처럼** 오염도가 오름 | **확정** |
| 집 정화 시간 | 정화제 1개로 24시간 | 제안 |

## 집안일 튜토리얼

외출 전에 하는 집안일 튜토리얼이다. 여기서부터 친구가 들어와 함께할 수 있다 (확정).

- **위에서 아래로 내려가는 흐름**이다 (확정).
- **현관 보수**에서는 집에 있는 가구를 부숴 자재로 만들어 막고, "밖에서도 가져와야 한다"는 메시지를 보여준다 (확정).
- **바이오쿨러는 이미지로만** 보여준다 (확정).

### 순서 (제안)

| 순서 | 위치 | 배우는 것 |
|---|---|---|
| 1 | 옥상 | 빗물받이 설치 |
| 2 | 옥탑방 | 모닥불 피우기, 물 끓이기와 요리 |
| 3 | 3층 (아이콘) | 의냥이의 몸 정화, 정화제 제작 |
| 4 | 2층 (아이콘) | 가구를 부숴 자재 만들기 |
| 5 | 1층 (아이콘) | 자재로 현관 보수. "밖에서도 가져와야 한다" 메시지 |
| 6 | 지하 (이미지) | 바이오쿨러 보여주기 |
| 7 | 옥상 | 도르래로 내려가 첫 외출 |
