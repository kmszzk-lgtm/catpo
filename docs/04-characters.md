# 캐릭터

## 구성 (확정 방향)

프로젝트 좀보이드처럼 캐릭터를 만들 때 **직업**과 **특성**을 고른다.

- **직업**: 시작 스킬과 고유 특전을 준다.
- **특성**: 좋은 특성은 포인트를 쓰고, 나쁜 특성은 포인트를 돌려준다. 포인트를 맞춰 캐릭터를 만든다.

시스템 구조는 참고하되, 직업 구성과 특성 이름, 효과는 이 게임의 규칙(수색, 귀환, 감염, 거점)에 맞춰 새로 설계한다.

## 직업 초안 (제안)

낮 수색, 귀환, 감염, 밤 거점 중 하나씩 강점을 갖도록 나눴다. 첫 버전은 6개로 시작한다.

| 직업 | 강점 분야 | 특전 예시 |
|---|---|---|
| 택배기사 | 운반 | 가방 무게 한도 증가. 지역 지도에서 출발 지점까지의 거리 표시 |
| 직업군인 | 전투 | 전투 스킬 시작치 높음. 직접 귀환(야간 전투) 시 공포 면역 |
| 약사 | 감염 대응 | 수색 중 약품 발견률 증가. 거점에서 억제제 제조 가능 |
| 응급구조사 | 치료 | 치료 효과 증가. 부상 회복 속도 증가 |
| 인테리어 기사 | 거점 | 방어 시설 건설 속도와 내구도 증가 |
| 편의점 알바생 | 식량 | 식량 발견률 증가. 상한 음식 판별 |

직업이 없는 대신 특성 포인트를 더 받는 "무직"을 둘지도 검토한다.

## 특성 초안 (제안)

| 좋은 특성 (포인트 사용) | 효과 |
|---|---|
| 야행성 | 밤 시야 증가. 직접 귀환 시 피로 감소 |
| 조용한 발걸음 | 수색 중 소음 감소 |
| 높은 면역력 | 감염도 상승량 감소 (감염 자체를 막지는 못함) |
| 빠른 회복 | 부상 회복 속도 증가 |
| 짐꾼 체질 | 가방 무게 한도 증가 |
| 튼튼한 위장 | 상한 음식을 먹어도 탈이 나지 않음 |

| 나쁜 특성 (포인트 획득) | 효과 |
|---|---|
| 겁쟁이 | 좀비가 가까우면 명중률 감소 |
| 근시 | 수색 중 시야 감소 |
| 대식가 | 식량 소모 증가 |
| 덜렁이 | 자동 귀환 '질주' 시 분실 증가. 수색 중 가끔 소음 |
| 허약 체질 | 최대 체력 감소 |
| 불면증 | 휴식 효율 감소 (휴식일 회복량 감소) |

포인트 값은 밸런스 표를 만들 때 정한다.

## 스킬 (제안)

직접 해본 행동으로 성장한다.

| 스킬 | 오르는 방법 | 효과 |
|---|---|---|
| 근접 전투 | 근접 무기로 공격 | 근접 피해, 무기 내구도 소모 감소 |
| 사격 | 총기 사용 | 명중률, 탄약 효율 |
| 은신 | 들키지 않고 이동 | 소음 감소, 유인 효율 |
| 수색 | 컨테이너 수색 | 수색 속도, 희귀 물자 발견률 |
| 응급처치 | 치료 | 치료량, 감염도 낮추기(검토) |
| 건설 | 거점 건설·수리 | 건설 속도, 시설 내구도 |

## 성격 (제안)

능력치와 별개로, 이벤트와 마지막 선택에만 영향을 주는 성격을 하나씩 둔다.
예: 이타적, 겁 많음, 냉정함, 가족 걱정. 자세한 예시는 [감염](03-infection.md#마지막-선택-이벤트-제안) 참고.

## 사망 (확정된 부분)

- 감염 후 10일이 지나면 완전 변이로 **죽는다.** 되살아나는 규칙은 없다.

## 미정

- 전투로 죽었을 때도 영구 사망인지
- 새 생존자를 얻는 방법 (수색 중 구조 이벤트 등)
- 전원 사망 시 게임 오버인지
- 혼자 플레이할 때 생존자를 1명만 운용하는지, 여러 명(NPC 동료)을 운용하는지
