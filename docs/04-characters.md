# 캐릭터

## 플레이 규칙 (확정)

- 캐릭터는 **집냥이, 군냥이, 의냥이, 길냥이** 4명으로 고정이다. 직접 만들지 않는다.
- **혼자 할 때**: 4명 중 **한 명을 골라** 플레이한다. 나머지 자리는 **AI가 활동**한다.
- **다른 사람이 들어오면**: 비어 있는 캐릭터 중 하나를 골라 플레이한다.
- 방장이 항상 집냥이로 플레이하는 것은 아니다. 다만 월드는 집냥이를 중심으로 하며, **집냥이가 죽으면 그 월드는 끝난다.**
- 플레이어 캐릭터는 모두 고양이 귀가 달린, 이미 감염된 상태다 ([세계관](00-world-and-start.md)).
- 튜토리얼 이후 연합이 생기면, 집냥이는 **연합의 수장**이 된다. 우호도가 쌓이면 AI팀 인원과 본 팀 인원을 맞바꿀 수 있다 ([연합과 AI팀](14-alliance.md)).

## 특성 선택 (확정)

- **튜토리얼 모드**: 기본 4명의 특성은 고정이고, **집냥이만** 특성을 추가로 고를 수 있다.
- **이지 모드부터**: 고유 특성을 뺀 **모든 특성을 추가하거나 제거해서** 조율할 수 있다. 남는 포인트 한도 안에서다.
- 특성은 월드를 만들 때부터 배분한다. AI에게 자동 배분을 맡길 수 있고, 처음부터 함께 있으면 로비에서 각자 자기 캐릭터의 특성을 고른다 ([특성 배분](12-difficulty-and-progression.md#특성-배분-확정)).
- 무직(집냥이)은 긍정·부정 특성 **선택 폭이 가장 크다.** 보너스 포인트처럼 처리한다.
- **업적이나 조건을 달성할 때마다** 새 게임에서 고를 수 있는 특성·특전 종류가 늘어난다. **포인트는 늘지 않는다.** 특전은 한 캐릭터에 몰아줄 수 있다 ([난이도와 성장](12-difficulty-and-progression.md)).

## 캐릭터 소개 (확정)

| 캐릭터 | 성별 | 직업 | 처음 있는 곳 | 고유 특성 (긍정 / 부정) |
|---|---|---|---|---|
| 집냥이 | 여성 | 무직 (백수) | 지하 1층 | 생활력 / 외출불가 |
| 군냥이 | 남성 | 군인 (말년휴가 중) | 2층 | 얼차려 / 부조리 |
| 의냥이 | 여성 | 의사 | 3층 | 전문의 / 태움 |
| 길냥이 | 여성 (숏헤어, 보이시해서 남성처럼 보임) | 도둑 | 옥탑방 | 생존본능 / 불안 |

### 집냥이

- 집 밖에 **절대 나가지 않는다.** 낮 수색 같은 외출 콘텐츠를 이용할 수 없다.
- 고유 특성
  - **외출불가**: 집 밖 활동 불가. 항상 집에만 있다.
  - **생활력**: 집 안에서 하는 **모든 활동에 보너스**가 붙는다.
- 외출하는 동료가 옥상 줄을 타고 오르내릴 때 **도르래를 돕는다.**
- 지하실에서 원리도 모르는 **바이오쿨러**에 물만 주며 냉장고로 쓰고 있었다.
- 취미는 **홈트, 독서, 드라마·영화 보기**였다. 쓸데없는 잡지식이 엄청 많아서 **책을 빨리 읽는다** ([서적](11-crafting-and-books.md#서적-확정)).
- **집냥이가 죽으면 월드가 끝난다.**

### 군냥이

- 말년휴가를 나온 군인이라 **장비가 없다.**
- 튜토리얼 시점에 이미 3층까지 확보하고 의냥이를 구해 둔 상태다.
- 현관이 조금 뚫리면 날을 세운 긴 나무 막대로 좀비냥들을 죽인다 (지하실 봉쇄 이벤트).
- **처음 튜토리얼을 끝낼 때(1회차만)**, 계단을 뚫고 올라온 거대 호랑이 좀비냥을 막아서서 다른 냥이들이 도망갈 시간을 벌고 **죽는다.** "희생" 업적이 달성된다. 그 뒤로는 함께 싸우거나 함께 도망갈 수 있다 ([엔딩과 거점 이전](13-endings-and-relocation.md)).
- **얼차려** (긍정)
  - 어떤 상황에서도 적응력이 좋다.
  - 깜짝 놀라지 않고 항상 경계 상태다. 예민해서 자다가도 잘 깬다.
  - 항상 주의 깊고 계산이 빠르다.
  - **외부 활동 경험치 보너스가 높다.**
  - **스트레스 생성량 -50%.** 그래서 의냥이의 태움 영향이 거의 없다 (확정).
- **부조리** (부정)
  - 집안일을 안 하려 한다.
  - **집 안 행동 경험치에 불이익**이 있다.

### 의냥이

- **시작 아이템**: 응급처치 도구 여러 개, 상비약, 진통제.
- 집 안 **정화 작업**을 마쳐서, 집 안에서는 오염도가 오르지 않는다. 튜토리얼에서 시설 전체를 소독해 모두의 오염도를 1로 만든다.
- 외출하고 돌아온 동료의 전신을 소독하고 항생제를 먹여 **오염도를 낮춘다.**
- 소독약, 락스, 술로 **정화제를 만든다.** 의료 레벨이 높은 다른 캐릭터도 만들 수 있다 ([정화제](09-home-life.md#정화제-확정)).
- **전문의** (긍정): 의료 행위 관련 행동 보너스가 높다.
  - 정화제는 소모품이라 **누가 써 줘도 효과가 같다.** 의냥이의 특성과 의료 레벨은 정화제를 **만드는 속도와 재료 절감**에 영향을 준다 (확정).
  - **상처 치료**는 누가 직접 처치하느냐가 영향을 준다 (확정, 아직 규칙 코드에는 없음).
- **태움** (부정)
  - 집안일을 안 하려 한다. 집 안 행동 경험치에 **조금** 불이익이 있다.
  - 의냥이가 집에 있으면 **가끔**, 집에 있는 사람 중 **무작위 1명**에게 스트레스를 준다. 상시도, 매시간도 아니다 (확정, 2026-11-08). 의냥이가 집 밖에 나가 있으면 생기지 않는다. 수치는 [스트레스](08-stress.md#태움-수치-제안) 참고.

### 길냥이

- 정체는 좀비 사태가 일어난 뒤 옥탑방에 숨어든 **도둑냥이**다.
- 숏헤어에 보이시해서 남성처럼 보이는 여성이다.
- 눈치가 빠르다. 예민하다. 모든 행동 속도가 빠른 편이다. 적응력이 뛰어나다.
- **생존본능** (긍정)
  - 배고픔과 목마름이 덜하다.
  - 스태미나 회복이 빠르고 소모가 적다.
  - 이동 속도와 행동 속도가 더 빠르다.
- **불안** (부정)
  - 안전해도 안전하다고 생각하지 않는다.
  - 식품을 먹을 때 충동적으로 더 먹는다.
  - 부상 상태일 때 의료품을 과하게 쓴다.
  - 스트레스를 더 많이 받아서 자주 풀어줘야 한다.
  - 자고 일어날 때 스트레스가 **추가로 더** 쌓인다. 약 **두 배**.
- **집 안에서 좋아하는 제작이 없다** (확정, Q95). 길냥이는 집냥이가 아니다. 집 안에서는 화투·트럼프 카드처럼 함께 노는 취미로 스트레스를 푼다.
- 도둑 출신이라는 배경을 살려 잠긴 문 따기 같은 특전을 줄 수 있다 (제안).

## 역할 정리

위 확정 내용을 비교하기 쉽게 모은 표다.

| 캐릭터 | 집 안 | 집 밖 |
|---|---|---|
| 집냥이 | 모든 활동 보너스 | 나갈 수 없음 |
| 군냥이 | 경험치 불이익 | 경험치 보너스 높음 |
| 의냥이 | 경험치 불이익 조금. 의료 행위는 보너스 | 보통 |
| 길냥이 | 보통 | 이동·행동 빠름, 소모 적음 |

## 상태 수치

확정된 특성에서 나온 수치들이다. 각 수치의 범위와 효과는 밸런스 표에서 정한다.

| 수치 | 근거 |
|---|---|
| 체력, 부상 | 의냥이 의료 보너스, 길냥이 의료품 과소비 |
| 배고픔, 목마름 | 길냥이 생존본능, 불안 |
| 스태미나 | 길냥이 생존본능 |
| 스트레스 | 기상, 외출, 부상, 동료 사망, 특성. 자세히는 [스트레스](08-stress.md) |
| 피로 | 스트레스가 높으면 더 빨리 피로해짐 ([스트레스](08-stress.md#높을-때-효과-확정)) |
| 오염도, 감염도 | [오염과 감염](03-infection.md) |
| 경험치 (집 안 행동 / 외부 활동) | 군냥이 얼차려·부조리, 의냥이 태움 |
| 이동 속도, 행동 속도 | 길냥이 생존본능 |
| 수면과 경계 | 군냥이 얼차려 (자다가도 잘 깸) |

## 일반 특성 초안 (제안)

집냥이가 고르거나 업적으로 해금될 특성 후보다.

| 좋은 특성 (포인트 사용) | 효과 |
|---|---|
| 야행성 | 밤 시야 증가. 직접 귀환 시 피로 감소 |
| 조용한 발걸음 | 수색 중 소음 감소 |
| 높은 면역력 | 오염도 상승량 감소 (물리면 감염되는 것은 막지 못함) |
| 빠른 회복 | 부상 회복 속도 증가 |
| 짐꾼 체질 | 가방 무게 한도 증가 |
| 튼튼한 위장 | 상한 음식을 먹어도 탈이 나지 않음 |

| 나쁜 특성 (포인트 획득) | 효과 |
|---|---|
| 겁쟁이 | 좀비가 가까우면 명중률 감소 |
| 근시 | 수색 중 시야 감소 |
| 대식가 | 식량 소모 증가 |
| 덜렁이 | 자동 귀환 '질주' 시 분실 증가. 수색 중 가끔 소음 |
| 허약 체질 | 최대 체력 감소 |
| 불면증 | 휴식 효율 감소 |

집냥이는 외출하지 않으므로, 집냥이용으로는 집 안 활동(제작, 요리, 치료, 경계, 도르래)에 영향을 주는 특성을 더 만들어야 한다.

## 스킬 (제안)

직접 해본 행동으로 성장한다. 경험치가 집 안 행동과 외부 활동으로 나뉘는 것은 **확정**.

| 스킬 | 오르는 방법 | 효과 |
|---|---|---|
| 근접 전투 | 근접 무기로 공격 | 근접 피해, 무기 내구도 소모 감소 |
| 사격 | 총기 사용 | 명중률, 탄약 효율 |
| 은신 | 들키지 않고 이동 | 소음 감소, 유인 효율 |
| 수색 | 컨테이너 수색 | 수색 속도, 희귀 물자 발견률 |
| 의료 | 치료, 몸 정화, 정화제 제작 | 치료량, 오염도를 낮추는 양. **의료 레벨이 높으면 정화제를 만들 수 있음 (확정)** |
| 건설·제작 | 거점 시설 설치, 제작 | 작업 속도, 시설 내구도 |

## 사망 (확정)

- **집냥이가 죽으면 월드가 끝난다.**
- 감염도가 100이 되면 완전 변이로 죽는다. 되살아나는 규칙은 없다.
- **집냥이가 죽어도 엔딩이 있다.**
- 다른 초기 캐릭터가 죽으면 **랜덤 능력치를 가진 랜덤 캐릭터**가 합류 요청을 하며 찾아온다. 기본으로 가지고 온 것은 조정할 수 없고, 관련 업적을 해금했으면 긍정·부정 특성을 추가·제거할 수 있다. 유니크 캐릭터일 수도, 평범한 캐릭터일 수도 있다 ([난이도와 성장](12-difficulty-and-progression.md#캐릭터가-죽으면-확정)).
