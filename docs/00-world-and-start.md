# 세계관과 게임 시작

## 제목 (확정)

**좀비냥**

## 세계관 (확정)

- 배경은 한국의 가상 도시 **목성시**다. 화성시를 모델로 했다.
- 좀비 바이러스의 증상은 **고양이화**다.
- **완전히 감염된 좀비**: 팔다리가 있지만 거의 고양이나 호랑이에 가까운 모습. 두 발로 서서 뛰어다닌다.
- **지역 보스**: 네 발로 걷는 호랑이 느낌.
- **플레이어 캐릭터**: 모두 고양이 귀가 달려 있다. 사실은 **이미 감염된 상태**다. 고양이 귀는 감염의 **안정된 초기 단계**다 ([감염](03-infection.md)).
- 언제부터 고양이 귀가 달렸는지는 게임 안에서 **설명하지 않는다.**

### 제안 메모

- 지명과 상호는 실제 이름(실제 화성시 지명, 편의점 브랜드 등) 대신 가상 이름을 쓴다.

## 거점: 옥탑방 주택 (확정)

3층 건물에 옥탑방이 있는 주택이다. 1층에는 방이 없고 현관과 계단만 있다.

| 층 | 처음 있는 캐릭터 | 상태 |
|---|---|---|
| 옥탑방·옥상 | 길냥이 | **집(본거지)**. 외출과 복귀는 옥상에 매단 줄로 |
| 3층 | 의냥이 | |
| 2층 | 군냥이 | |
| 1층 | 없음 | 현관과 계단뿐. 현관을 가구로 막아 **아예 못 들어오게** 한 상태로 시작 |
| 지하 1층 | 집냥이 | **게임 시작 위치** |

- **집은 곧 옥탑방이다.** 함께 플레이하는 로비이자 항상 활성화된 공간이다.
- **외출과 복귀**: 옥상(옥탑방)에 매단 줄과 **급조한 도르래**로 내려갔다 올라간다. **집냥이가 도르래를 돕는다.**
- **도르래 업그레이드**: 재료를 더 가져오면 한 번에 올리고 내릴 수 있는 **무게나 슬롯**이 늘어난다.
- **추가 시설**은 지하, 2층, 3층에 **설치만 한다.** 플레이어가 그 층으로 직접 이동하지 않는다. 제작할 때 캐릭터가 해당 층으로 가서 작업하는 **연출만** 보여준다.

### 층별 시설 배치 (제안)

| 층 | 시설 예시 |
|---|---|
| 지하 1층 | 저장고 (서늘해서 식량이 덜 상함), 물탱크 |
| 2층 | 작업대 (무기·도구 제작), 바리케이드 자재 보관 |
| 3층 | 의무실 (치료, 억제제 제조) |
| 옥탑방·옥상 | 휴식, 망루 (습격 미리 보기), 빗물 받기, 도르래 |

## 월드와 로비 (확정)

- **집(옥탑방)**: 멀티플레이 장소이자 로비. 항상 활성화되어 있다.
- **집 밖**: 싱글플레이 장소. 여러 명이 외출하면 **서로 다른 지역으로만** 갈 수 있다. 같은 지역에 겹쳐 가지 않게 해서 효율을 극대화한다.
- 캐릭터 운용 규칙은 [캐릭터](04-characters.md#플레이-규칙-확정) 참고.

## 게임 시작 흐름 (확정)

```
새 월드 만들기 (로비)
  → 특성 고르기 (혼자면 집냥이만)
  → 지하 1층에서 집냥이로 시작
  → 튜토리얼: 지하에서 옥탑방까지 집을 확보하면서
      2층 군냥이, 3층 의냥이, 옥탑방 길냥이가 합류
  → 4명 합류 = 튜토리얼 끝, 본게임 시작
```

튜토리얼에서 각 층을 어떻게 확보하는지, 무엇을 가르치는지는 **미정** ([Q25](open-questions.md)).
