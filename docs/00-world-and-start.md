# 세계관과 게임 시작

## 제목 (확정)

**좀비냥**

## 세계관 (확정)

- 배경은 한국의 가상 도시 **목성시**다. 화성시를 모델로 했다.
- 좀비 바이러스의 증상은 **고양이화**다.
- **완전히 감염된 좀비**: 팔다리가 있지만 거의 고양이나 호랑이에 가까운 모습. 두 발로 서서 뛰어다닌다.
- **지역 보스**: 네 발로 걷는 호랑이 느낌.
- **플레이어 캐릭터**: 모두 고양이 귀가 달려 있다. 사실은 **이미 감염된 상태**다.
- 언제부터 고양이 귀가 달렸는지는 게임 안에서 **설명하지 않는다.**

### 제안 메모

- 지명과 상호는 실제 이름(실제 화성시 지명, 편의점 브랜드 등) 대신 가상 이름을 쓴다.
- 플레이어 캐릭터가 이미 감염된 상태라는 설정과 [감염](03-infection.md) 규칙의 관계는 **미정** ([Q21](open-questions.md)).

## 거점 (확정)

- **지하 벙커에서 시작**한다.
- 일부러 만든 벙커가 아니라, **옥탑방이 있는 주택**의 지하다.

### 제안 (확인 필요)

거점을 주택 전체로 보고, 지하에서 시작해 한 층씩 되찾아 넓혀가면 거점 성장이 눈에 보인다.

| 단계 | 공간 | 열리는 기능 예시 |
|---|---|---|
| 시작 | 지하 | 잠자리, 창고 |
| 2 | 1층 | 부엌(요리), 작업대(제작) |
| 3 | 2층 | 의무실(치료), 방어 시설 |
| 4 | 옥탑방 | 망루(습격 미리 보기), 빗물 받기(물) |

## 캐릭터 구성 (확정)

- 캐릭터를 **직접 만들지 않는다.** 정해진 캐릭터로 시작한다.
- 첫 캐릭터는 **집냥이**, 직업은 **무직(백수)**.
- 무직은 긍정·부정 **특성 선택 폭이 가장 크다.** 보너스 포인트처럼 처리한다.
- **업적을 해금할 때마다** 새 게임에서 고를 수 있는 **특성 종류가 늘어난다.** 포인트는 늘지 않는다.
- **싱글플레이와 멀티플레이를 따로 구분하지 않는다.** 게임 시작부터 캐릭터 4명 자리를 채운다.
- **튜토리얼을 마치면 4명이 모두 합류**하고, 그때부터 본게임이 시작된다.

자세한 내용은 [캐릭터](04-characters.md) 참고.

## 게임 시작 흐름 (초안, 제안)

```
타이틀 → 새 게임
  → 집냥이 특성 고르기
  → 오프닝: 주택 지하에서 지내는 집냥이 (고양이 귀에 대한 설명 없음)
  → 튜토리얼: 이동, 수색, 전투, 귀환을 배우면서 동료 3명이 차례로 합류
  → 4명 합류 = 튜토리얼 끝, 본게임 시작
```

튜토리얼의 구체적인 내용과 동료가 합류하는 계기는 **미정** ([Q22](open-questions.md), [Q25](open-questions.md)).
