# 시간과 계절

## 하루 (확정)

- 하루는 **24시간**이다.

## 계절 (확정)

- **봄, 여름, 가을, 겨울** 각 **30일**. 한 달마다 계절이 바뀐다. (1년 = 120일)
- 해가 뜨고 지는 시간이 계절마다 달라서, **외출 가능 시간**도 달라진다.

## 외출 가능 시간 (확정)

| 계절 | 외출 가능 시간 | 길이 |
|---|---|---|
| 봄 | 09:00 ~ 18:00 | 9시간 |
| 여름 | 08:00 ~ 20:00 | 12시간 |
| 가을 | 09:00 ~ 18:00 | 9시간 |
| 겨울 | 10:00 ~ 16:00 | 6시간 |

- 기본 외출 시간은 09:00~18:00이고, 여름과 겨울이 확정되어 있다. 봄과 가을은 기본 시간으로 이해했다 ([Q33](open-questions.md)에서 확인).
- 외출 가능 시간 안이라면 **인원수와 관계없이 각자 원할 때** 외출할 수 있다.
- 끝 시각까지 출발 지점으로 돌아오지 못하면 [시간 초과 규칙](02-day-expedition.md#시간-초과-확정)이 적용된다.

## 시간대별 좀비 (확정)

- **12:00에 가장 느리고, 00:00에 가장 빠르다.**
- 아침에는 둔하고, 느리고, 반응도 잘 안 한다.
- 그래서 늦게 돌아올수록 귀환이 점점 어려워진다.

### 속도 곡선 (제안)

| 시각 | 좀비 속도 (기준 1.0) |
|---|---|
| 12:00 | 0.6 |
| 09:00, 15:00 | 0.7 |
| 06:00, 18:00 | 1.0 |
| 21:00 | 1.25 |
| 00:00 | 1.4 |

정오와 자정을 양 끝으로 하는 부드러운 곡선(코사인)으로 계산한다. 반응 범위(시야, 청각)도 같은 곡선을 따른다.

## 실제 시간과 게임 시간 (미정)

앞서 확정한 "수색 약 10분"과 게임 시계를 어떻게 맞출지 정해야 한다 ([Q29](open-questions.md)).

**제안**: 집 밖에서는 실제 1분 = 게임 1시간.

| 계절 | 외출 가능 시간 | 실제 시간 |
|---|---|---|
| 봄·가을 | 9시간 | 9분 (기획 의도인 약 10분에 맞음) |
| 여름 | 12시간 | 12분 |
| 겨울 | 6시간 | 6분 |

- 계절마다 수색 시간이 달라져서, 여름은 많이 모으는 시기, 겨울은 버티는 시기가 된다.
- 직접 귀환의 3분·5분은 해 진 뒤 게임 시각으로 3시간·5시간이 된다. 봄 기준으로 21:00까지 오면 무사, 23:00까지 오면 다음 날 휴식, 그 뒤는 감염. 자정에 가까울수록 좀비가 빨라지는 규칙과도 맞는다.

## 집에 있을 때의 시간 (미정)

- 모두 집에 있는 밤에도 시간이 실제 시간처럼 흐르는지, 잠을 자서 아침으로 넘기는지 ([Q30](open-questions.md))
- 여러 명이 접속해 있을 때 누구 기준으로 시간을 넘기는지

## 계절의 다른 효과 (제안)

외출 시간 외에 검토할 수 있는 효과다.

| 계절 | 효과 예시 |
|---|---|
| 봄 | 기본 |
| 여름 | 식량이 빨리 상함. 목마름이 빨리 참 |
| 가을 | 수확 이벤트, 식량을 모아두기 좋은 시기 |
| 겨울 | 추위(난방 필요). 식량이 덜 상함. 외출 시간 짧음 |
