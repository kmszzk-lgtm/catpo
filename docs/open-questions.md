# 미정 사항

번호로 부르면 대화에서 쉽게 가리킬 수 있다. 정해지면 해당 문서에 반영하고 [결정 기록](decisions.md)에 남긴 뒤 여기서 지운다. 번호는 다시 매기지 않는다.

## 지금 확인할 것

| 번호 | 질문 | 추천안 |
|---|---|---|
| Q64 | 이 레포는 공개 레포다. 기준 건물의 정확한 번지를 문서에 적어도 되나? | 동네 단위(남양읍 남양리)까지만 적고, 정확한 번지는 비공개로 보관 |
| Q65 | 실제 지도를 어떻게 게임 맵으로 옮기나? | 지도는 참고만 하고 직접 다시 그리거나, 오픈스트리트맵 데이터를 출처 표기와 함께 사용 |
| Q66 | 서적 이해 조건 예시가 방향에 맞나? | [제작과 서적](11-crafting-and-books.md#이해-조건-제안-확인-필요)의 표대로 |
