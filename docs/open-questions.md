| Q102 | 공격키·퀵슬롯과 2층 전투 프롤로그는 어떻게 하나? | 집에서 이동과 상호작용은 그대로. 공격키는 빼고, 프롤로그는 선택지로 진행하는 연출 장면으로. 퀵슬롯은 파견 때 "바로 쓸 물건" 칸으로 |
| Q103 | 시간 초과 귀환(자동 귀환·직접 귀환)은 파견에서 어떻게 되나? | 해 지기 전에 못 돌아오면 보고에 "밤길" 일이 생기고, 사람이 맡았으면 "미끼 쓰고 빨리 / 숨어서 천천히"를 고른다. 확정된 대가(물자 손실, 부상, 감염 가능)는 그대로 |
| Q104 | 혼자 할 때 일시정지는? | 혼자일 때만 메뉴를 열거나 앱을 내리면 멈춤. 멀티에서는 멈추지 않음 |
| Q99 | 집냥이가 집안 활동으로 푸는 스트레스는 얼마나? | 활동 1시간에 4. 좋아하는 요리는 한 번에 5 더. 하루 5~6시간 집안일을 하면 태움을 버팀 |
| Q83 | 우호도는 어떻게 오르고 내리나? | [연합과 AI팀](14-alliance.md#우호도가-오르고-내리는-경우)의 표대로 |
| Q84 | 공물은 얼마나 자주, 무엇을 보내나? AI팀은 무엇을 요청하나? | [연합과 AI팀](14-alliance.md#공물과-요청)의 표대로 |
| Q85 | 첫 AI팀(농부, 의사, 목수, 대장장이) 캐릭터의 이름과 리더는? | 기획자가 정함. 리더는 농부(팀이 텃밭으로 버텨 왔으니까) |
| Q65 | 실제 지도를 어떻게 게임 맵으로 옮기나? | 지도는 참고만 하고 직접 다시 그리거나, 오픈스트리트맵 데이터를 출처 표기와 함께 사용 |
| Q66 | 서적 이해 조건 예시가 방향에 맞나? | [제작과 서적](11-crafting-and-books.md#이해-조건-제안-확인-필요)의 표대로 |
