# 미정 사항

번호로 부르면 대화에서 쉽게 가리킬 수 있다. 정해지면 해당 문서에 반영하고 [결정 기록](decisions.md)에 남긴 뒤 여기서 지운다. 번호는 다시 매기지 않는다.

## 게임 시작 (지금 설계 중)

| 번호 | 질문 | 추천안 |
|---|---|---|
| Q21 | 캐릭터가 이미 감염된 상태(고양이 귀)라는 설정과, 물림·야간 초과로 "감염"되면 10일 뒤 변이하는 규칙은 어떻게 이어지나? | 고양이 귀는 안정된 초기 단계, 게임 속 "감염"은 그 상태가 **발병**해 변이가 진행되는 것. 완치제는 발병 전(고양이 귀 상태)으로 되돌림 |
| Q22 | 나머지 3명은 누구인가? 이름, 직업, 성격이 정해진 캐릭터인가? | 정해진 캐릭터 3명. 직업은 역할이 겹치지 않게 (예: 전투, 치료, 거점) |
| Q23 | 혼자 할 때 4명을 어떻게 운용하나? 하루에 몇 명이 수색을 나가나? | 하루에 1명을 골라 직접 수색(약 10분). 나머지 3명은 거점 일(제작, 치료, 경계)을 맡음 |
| Q24 | 특성은 집냥이만 고르나, 4명 모두 고르나? | 4명 모두 고르되 무직인 집냥이의 선택 폭이 가장 넓음 |
| Q25 | 튜토리얼은 어디서 무엇을 배우고, 동료 3명은 어떤 계기로 합류하나? | 주택 안 → 골목 → 가까운 상가 순으로 넓히며 이동·수색·전투·귀환을 하나씩 배우고, 단계마다 동료 1명씩 구출 |
| Q26 | 친구가 접속하면 캐릭터를 어떻게 맡나? | 방장의 게임에 들어와 남은 캐릭터 중 하나를 맡음. 나가면 다시 NPC처럼 행동 |
| Q27 | 업적 목록과, 업적마다 해금되는 특성 | 밸런스 표 이후에 정함 |
| Q28 | 거점은 지하만인가, 주택 전체(지하~옥탑방)를 층별로 넓혀가나? | 층별 확장 ([세계관과 게임 시작](00-world-and-start.md#제안-확인-필요) 표 참고) |

## 낮 수색과 감염

| 번호 | 질문 | 추천안 |
|---|---|---|
| Q1 | 시간 초과 기준: 10분 수색이 끝나는 순간 밤이 되며 선택창이 뜨고, 직접 귀환의 3분·5분은 그 순간부터 재는가? | 그렇다. 시계 표시로 18:00 해 짐, 21:00 무사 마감, 23:00 감염 마감 |
| Q2 | 자동 귀환의 대가(물자 소모 / 미끼 / 분실)를 누가 고르나? | 플레이어가 고르고 스탯이 성공률과 손실량에 영향 |
| Q3 | 낮 수색 중 물리거나 긁혀도 감염되나? | 그렇다. 감염도 게이지 하나로 통일 |
| Q4 | 직접 귀환 중 죽을 수 있나? 5분을 넘겨도 계속 버틸 수 있나? | 죽을 수 있다. 5분 이후에도 이동은 가능하지만 감염 확정 |
| Q5 | 억제제·완치제는 어디서 얻나? 억제제 1회 효과는? | 억제제: 병원·약국 수색과 약사 제조, +2일. 완치제: 고위험 지역에서만 드물게 |
| Q6 | 하루에 지역 1곳만 가나, 여러 곳을 들를 수 있나? | 1곳 (10분 수색 기준). Q23과 함께 정함 |

| 번호 | 질문 | 추천안 |
|---|---|---|

| Q12 | 게임 목표: 무한 생존 또는 엔딩(구조, 탈출)? | 미정. 엔딩이 있으면 난이도 곡선을 짜기 쉬움. "왜 우리는 완전히 변이하지 않았나"를 엔딩의 실마리로 쓸 수 있음 |
| Q13 | 밤 습격 방식: 배치형, 선택지형, 실시간? | 배치형 또는 선택지형으로 시작 |
| Q15 | 함께 플레이할 때 선택 충돌 처리: 투표 또는 방장 결정? | 미정 |
| Q16 | 자원 공유: 공용 창고만, 또는 공용 창고 + 개인 인벤토리? | 공용 창고 + 개인 인벤토리 |
| Q17 | 수익 모델: 유료 구매, 광고, 인앱 결제? | 미정 |
