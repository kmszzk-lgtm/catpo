# 미정 사항

번호로 부르면 대화에서 쉽게 가리킬 수 있다. 정해지면 해당 문서에 반영하고 [결정 기록](decisions.md)에 남긴 뒤 여기서 지운다. 번호는 다시 매기지 않는다.

## 지금 확인할 것

| 번호 | 질문 | 추천안 |
|---|---|---|
| Q49 | 감염도를 1~100 하나로 묶는 안이 맞나? 50을 발병선으로, 그 뒤로는 집에서도 스스로 올라 10일 뒤 100 | [감염도](03-infection.md#하나의-게이지로-정리-제안-확인-필요)의 표대로 |
| Q50 | 봉쇄 이벤트가 가을 무작위로 바뀌었는데, 현관 보수를 소홀히 해서 일찍 생기는 경우와 그때의 선택지(즉시 봉쇄 / 약품으로 버티기)는 그대로인가? | 그대로. 가을 전에 일찍 생기면 선택지, 가을에 무작위로 생기면 선택 없이 봉쇄 |
| Q48 | 아래층은 이미지로만 존재하는데, 지하에서 2층까지 가는 프롤로그는 어떻게 보여주나? | 일러스트 컷과 간단한 터치 연출. 2층 몸싸움은 타이밍 맞춰 누르는 방식 |
| Q46 | 집안일 튜토리얼 세부 순서 (위에서 아래로는 확정) | 옥상 빗물받이 → 옥탑방 모닥불 → 3층 정화 → 2층 가구 부수기 → 1층 현관 보수 → 지하 바이오쿨러(이미지) → 첫 외출 |
| Q45 | 현관 내구도는 얼마나 빨리 줄고, 무엇으로 보수하나? | 매일 조금씩 줄고, 가구를 부순 자재·판자·테이프로 보수. 수치는 밸런스 표에서 |
