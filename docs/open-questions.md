# 미정 사항

번호로 부르면 대화에서 쉽게 가리킬 수 있다. 정해지면 해당 문서에 반영하고 [결정 기록](decisions.md)에 남긴 뒤 여기서 지운다. 번호는 다시 매기지 않는다.

## 다음 설계: 집안일 튜토리얼과 첫 외출

| 번호 | 질문 | 추천안 |
|---|---|---|
| Q41 | 집안일에는 어떤 것들이 있나? 튜토리얼에서 무엇을 가르치나? | 요리, 물 끓이기(정화), 시설 설치·수리, 도르래 조작, 경계 서기. 튜토리얼은 요리 → 시설 설치 → 도르래 순 |
| Q42 | 전기가 끊긴 집에서 물과 불은 어떻게 해결하나? 수도는 나오나? | 수도도 끊김. 물은 수색으로 구하거나 옥상 빗물 받기. 불은 휴대용 버너와 가스 |
| Q40 | 의냥이와 길냥이는 튜토리얼에서 언제, 어떻게 합류하나? | 군냥이가 3층을 확보하며 의냥이를 이미 구해 둠. 옥탑방에서 숨어 있던 길냥이와 마주침 |

## 시간과 외출

| 번호 | 질문 | 추천안 |
|---|---|---|
| Q29 | 시계 속도: 1년 약 100시간(확정)에 맞추려면 게임 1시간을 실제 몇 분으로 하나? | 실제 약 3분 (밤은 잠으로 넘긴다고 보고 계산). 봄 외출 약 27분, 여름 36분, 겨울 18분 |
| Q32 | 하루에 여러 번 외출할 수 있나? | 외출 가능 시간 안이면 다시 나갈 수 있음. 수색 1회 약 10분이라 봄에는 하루 2번 정도 |
| Q33 | 봄과 가을의 외출 가능 시간은 기본값(09:00~18:00)이 맞나? | 그렇다 |
| Q36 | AI 파견 중 부상, 감염, 사망이 생길 수 있나? | 지역 위험도에 따라 낮은 확률로 부상·감염도 상승. 사망은 없음 |
| Q37 | 사람이 수색 중인 지역에 AI를 보낼 수 있나? | 없음 (서로 다른 지역 규칙과 같게) |

## 캐릭터와 스트레스

| 번호 | 질문 | 추천안 |
|---|---|---|
| Q38 | 캐릭터마다 좋아하는 제작과 싫어하는 제작은? | [스트레스](08-stress.md#취향) 문서의 예시안 |
| Q39 | 스트레스 수치 범위와 단계, 100이 되면 어떻게 되나? 군냥이 -50%는 모든 원인에 적용되나? | 0~100, 보통·예민·한계·붕괴 4단계. -50%는 모든 원인에 적용 |
| Q34 | 월드를 만들 때 로비에 2~3명만 있으면 특성 선택은? | 있는 사람만 자기 캐릭터 특성을 고르고, 나머지는 기본값 |
| Q8 | 집냥이 외의 캐릭터가 죽으면 그 자리는 어떻게 되나? 그 캐릭터를 하던 사람은? | 미정. 4명 고정 구조라 중요함 |
| Q7 | 전투로 죽어도 영구 사망인가? | 그렇다 |
| Q27 | 업적 목록과, 업적마다 해금되는 특성 | 밸런스 표 이후에 정함 |

## 수색과 감염 세부

| 번호 | 질문 | 추천안 |
|---|---|---|
| Q1 | 시간 초과 기준: 외출 가능 시간이 끝나는 순간 선택창이 뜨고, 직접 귀환의 3분·5분은 그 순간부터 재는가? | 그렇다 |
| Q2 | 자동 귀환의 대가(물자 소모 / 미끼 / 분실)를 누가 고르나? | 플레이어가 고르고 스탯이 성공률과 손실량에 영향 |
| Q3 | 낮 수색 중 물리거나 긁혀도 감염(발병)되나? | 그렇다. 감염도 게이지 하나로 통일 |
| Q4 | 직접 귀환 중 죽을 수 있나? 5분을 넘겨도 계속 버틸 수 있나? | 죽을 수 있다. 5분 이후에도 이동은 가능하지만 감염 확정 |
| Q5 | 억제제·완치제는 어디서 얻나? 억제제 1회 효과는? | 억제제: 병원·약국 수색과 의냥이 제조, +2일. 완치제: 고위험 지역에서만 드물게 |
