# 미정 사항

번호로 부르면 대화에서 쉽게 가리킬 수 있다. 정해지면 해당 문서에 반영하고 [결정 기록](decisions.md)에 남긴 뒤 여기서 지운다.

## 핵심 루프에 걸리는 것 (먼저 정하기)

| 번호 | 질문 | 추천안 |
|---|---|---|
| Q1 | 시간 초과 기준: 10분 수색이 끝나는 순간 밤이 되며 선택창이 뜨고, 직접 귀환의 3분·5분은 그 순간부터 재는가? | 그렇다. 시계 표시로 18:00 해 짐, 21:00 무사 마감, 23:00 감염 마감 |
| Q2 | 자동 귀환의 대가(물자 소모 / 미끼 / 분실)를 누가 고르나? | 플레이어가 고르고 스탯이 성공률과 손실량에 영향 |
| Q3 | 낮 수색 중 물리거나 긁혀도 감염되나? | 그렇다. 감염도 게이지 하나로 통일 |
| Q4 | 직접 귀환 중 죽을 수 있나? 5분을 넘겨도 계속 버틸 수 있나? | 죽을 수 있다. 5분 이후에도 이동은 가능하지만 감염 확정 |
| Q5 | 억제제·완치제는 어디서 얻나? 억제제 1회 효과는? | 억제제: 병원·약국 수색과 약사 제조, +2일. 완치제: 고위험 지역에서만 드물게 |
| Q6 | 하루에 지역 1곳만 가나, 여러 곳을 들를 수 있나? | 1곳 (10분 수색 기준) |

## 캐릭터와 진행

| 번호 | 질문 | 추천안 |
|---|---|---|
| Q7 | 전투로 죽어도 영구 사망인가? | 그렇다 |
| Q8 | 새 생존자는 어떻게 얻나? 전원 사망하면 게임 오버인가? | 수색 중 구조 이벤트로 합류. 전원 사망 시 게임 오버 |
| Q9 | 휴식일에 혼자 플레이 중이면 하루를 건너뛰나? | 혼자일 때도 생존자 여러 명(NPC 동료)을 두고, 쉬는 캐릭터 대신 다른 생존자가 나감 |
| Q10 | 직업·특성 초안([캐릭터](04-characters.md))이 방향에 맞나? | 초안대로 시작 후 조정 |

## 큰 방향

| 번호 | 질문 | 추천안 |
|---|---|---|
| Q11 | 시점: 탑다운 또는 쿼터뷰? | 탑다운 (혼자 개발할 때 부담이 훨씬 적음) |
| Q12 | 게임 목표: 무한 생존 또는 엔딩(구조, 탈출)? | 미정. 엔딩이 있으면 난이도 곡선을 짜기 쉬움 |
| Q13 | 밤 습격 방식: 배치형, 선택지형, 실시간? | 배치형 또는 선택지형으로 시작 |
| Q14 | 협동 인원: 최대 4명이 맞나? | 이전 대화 기준 4명. 확인 필요 |
| Q15 | 협동 중 선택 충돌 처리: 투표 또는 방장 결정? | 미정 |
| Q16 | 자원 공유: 공용 창고만, 또는 공용 창고 + 개인 인벤토리? | 공용 창고 + 개인 인벤토리 |
| Q17 | 수익 모델: 유료 구매, 광고, 인앱 결제? | 미정 |
| Q18 | 게임 제목 | 미정 (현재 코드명 `catpo`) |
