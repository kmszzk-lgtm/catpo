# 제작과 서적

## 무게와 도구 (확정)

- 바깥 필드는 넓다. 제약은 **무게**다. 멀쩡한 물건을 한 번에 많이 가져오기 힘들다.
- 재료만 가져오는 것이 아니라, **장비로 쓸 도구**도 가져와야 한다.
- 편의점 근처에 **공구점**이 있다.

## 분해와 결합 (확정)

- 무거운 작업 도구는 통째로 가져올 수 없다. **분해해서 나눠 담아** 가져온다.
- **분해하려면 지식이 필요하다.**
- 가져온 부품은 집에서 다시 **결합**한다.

```
공구점에서 무거운 도구 발견
  → (레시피를 알면) 분해
  → 부품을 나눠 담아 여러 번에 걸쳐 운반 (무게 제한, 도르래)
  → 집에서 결합 → 장비로 사용
```

### 예시 (제안)

| 무거운 도구 | 분해하면 | 결합 후 쓰임 |
|---|---|---|
| 공구점 작업대 | 상판, 다리, 바이스 | 2층 작업대 업그레이드 (더 많은 제작) |
| 대형 공구함 | 공구 세트 여러 개 | 분해·수리 속도 증가 |
| 쇠파이프 선반 | 쇠파이프, 볼트 | 무기 재료, 바리케이드 보강 |
| 손수레 | 바퀴, 손잡이, 적재함 | (검토) 바깥에서 무게 한도 증가 |

## 서적 (확정)

- **서적을 읽고** 분해, 결합, 제작 같은 **레시피를 배운다.**
- 서적은 여러 기능을 한다. 그중 하나로 **무기 숙련도, 제작 숙련도** 같은 경험치에 **부스트**를 준다.

### 종류 (제안)

| 종류 | 예시 | 효과 |
|---|---|---|
| 레시피 책 | 공구 다루기, 목공 입문, 응급 의학 | 분해·결합·제작 레시피를 배움 |
| 숙련 교본 | 호신술 교본, 목공 잡지 | 일정 기간 해당 숙련도 경험치 증가 |
| 지도·안내서 | 목성시 지도, 상가 안내 책자 | 방향별로 무엇이 있는지 미리 알게 됨 |

### 읽기 (제안, 확인 필요)

- 책은 집에서 읽는다. 읽는 데 시간이 걸린다.
- 레시피는 **읽은 캐릭터만** 배운다. 그래서 누구에게 어떤 책을 읽힐지가 역할 분담이 된다.
- 집냥이는 생활력 덕분에 집에서 읽는 속도가 빠르다. 대신 바깥 일과 관련된 레시피를 배워도 직접 쓸 일은 적다.

자세한 방식은 **미정** ([Q63](open-questions.md)).

## 숙련도

- **무기 숙련도, 제작 숙련도** 같은 숙련도가 있다 (확정). 직접 해본 행동으로 오른다.
- 전체 목록은 [캐릭터](04-characters.md#스킬-제안)의 스킬 초안을 숙련도로 이어서 쓴다 (제안).
