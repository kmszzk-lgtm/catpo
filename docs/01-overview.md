# 기획 개요

## 한 줄 소개

고양이화 바이러스가 퍼진 가상 도시 목성시에서, 고양이 귀가 달린 생존자 4명(집냥이, 군냥이, 의냥이, 길냥이)이 옥탑방 주택을 거점 삼아 버티는 모바일 생존 게임. 집은 함께, 집 밖은 혼자 플레이한다.

## 핵심 루프 (하루)

```
집 (옥탑방, 함께): 항상 열려 있는 로비. 정리·배급·제작·치료·AI 파견
  ↓ 외출 가능 시간 (봄 09~18시, 여름 08~20시, 겨울 10~16시)
집 밖 (혼자): 각자 원할 때 옥상 줄로 내려감 → 사거리에서 서로 다른 방향으로 수색 → 집으로 복귀
  ↓        └ 시간 초과 시: 자동 귀환 또는 직접 귀환 (밤 전투, 자정에 가까울수록 좀비가 빨라짐)
밤 (집, 함께): 소지품은 공용 창고로 → 시설 설치·제작·치료·독서 → 현관 보수 (뚫리면 게임 오버)
  ↓
다음 날 (30일마다 계절이 바뀜)
```

자세한 규칙은 [외출: 수색과 귀환](02-day-expedition.md), [집: 거점과 협동](05-night-base.md), [시간과 계절](07-time-and-seasons.md) 참고.

## 재미의 중심

1. **자원 압박**: 식량, 물, 체력, 탄약이 늘 부족해서 선택이 고민돼야 한다.
2. **리스크와 보상**: 위험한 지역일수록 좋은 물자가 나온다. 오래 수색할수록 많이 얻지만 위험도 커진다.
3. **귀환 판단**: "더 뒤질까, 지금 나갈까." 시간 안에 못 나가면 대가를 치른다.
4. **오염과 감염**: 바깥에 오래 있을수록 오염도가 쌓이고, 물리거나 오염도가 50을 넘으면 감염된다. 정화제, 억제제, 완치제를 구하러 위험 지역에 가야 할 이유가 생긴다.
5. **캐릭터 애착**: 개성이 뚜렷한 고정 캐릭터 4명이 죽을 수 있고, 캐릭터마다 마지막 선택 이벤트가 있다. 집냥이가 죽으면 월드가 끝난다.
6. **역할 분담**: 집냥이는 집 안 전문, 군냥이는 외부 활동 전문처럼 캐릭터마다 강점이 달라서 협동할 이유가 생긴다.

## 집 밖

- 집 앞 사거리에서 **4방향**으로 나간다. 한 방향에는 한 캐릭터만 나갈 수 있다 (확정).
- 필드는 넓고, 제약은 **무게**다. 물자는 한 번 수거하면 다시 나오지 않아서, 갈수록 더 멀리 나가야 한다 (확정).
- 필드는 실제 화성시청 주변 지도를 배경으로 하고, 집 근처 편의점 두 곳과 공구점은 지도의 빈 공간에 넣는다 (확정).
- 차량을 타고 다니는 시스템은 없다. 길가 차량은 수색 대상이고, 총기는 경찰서가 아니라 경찰차·경찰 좀비·사고 차량에서 얻는다 (확정).

## 개발 원칙 (제안)

- **혼자 하는 플레이 먼저, 친구 접속은 나중에.** 모드 구분은 없지만, 개발은 혼자 4명을 운용하는 플레이를 완성한 뒤 친구 접속을 붙인다.
- **게임 상태는 하나의 데이터 구조로.** 저장과 멀티 동기화가 쉬워진다.
- **콘텐츠는 데이터로 분리.** 아이템, 지역, 이벤트, 직업, 특성은 JSON 같은 데이터 파일로 관리해서 코드 수정 없이 늘린다.
- **작게 시작.** 첫 버전은 캐릭터 4명, 일반 특성 12개 정도, 집 근처(편의점 두 곳, 공구점)부터 만든다.
- **아트와 사운드는 무료 에셋으로 시작해서 나중에 교체.**
