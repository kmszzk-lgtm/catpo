# 기획 개요

## 한 줄 소개

고양이화 바이러스가 퍼진 가상 도시 목성시에서, 고양이 귀가 달린 생존자 4명이 낮에는 각자 지역을 수색하고 밤에는 주택 지하 거점에 모여 함께 버티는 모바일 생존 게임.

## 핵심 루프 (하루)

```
아침: 생존자 임무 배정
  ↓
낮 (각자): 지역 선택 → 지역 수색 (약 10분) → 출발 지점으로 복귀
  ↓        └ 시간 초과 시: 자동 귀환 또는 직접 귀환 (야간 전투)
밤 (함께): 거점 귀환 → 전리품 정리·배급 → 제작·건설·치료 → 습격 대응
  ↓
다음 날
```

자세한 규칙은 [낮: 수색과 귀환](02-day-expedition.md), [밤: 거점과 협동](05-night-base.md) 참고.

## 재미의 중심

1. **자원 압박**: 식량, 물, 체력, 탄약이 늘 부족해서 선택이 고민돼야 한다.
2. **리스크와 보상**: 위험한 지역일수록 좋은 물자가 나온다. 오래 수색할수록 많이 얻지만 위험도 커진다.
3. **귀환 판단**: "더 뒤질까, 지금 나갈까." 시간 안에 못 나가면 대가를 치른다.
4. **감염 카운트다운**: 감염되면 10일. 억제제와 완치제를 찾아 위험 지역에 가야 할 이유가 생긴다.
5. **캐릭터 애착**: 직업과 특성으로 만든 캐릭터가 영구히 죽을 수 있고, 마지막 선택 이벤트가 있다.
6. **역할 분담**: 직업에 따라 낮 수색과 밤 거점 일의 강점이 달라서 협동할 이유가 생긴다.

## 지역 예시

장소마다 나오는 물자가 다르다. (이전 대화에서 나온 예시, **제안**)

| 지역 | 주요 물자 | 위험도 |
|---|---|---|
| 편의점 | 식량, 물 | 낮음 |
| 마트 | 식량 대량 | 중간 |
| 주유소 | 연료, 공구 | 중간 |
| 학교 | 잡동사니, 제작 재료 | 중간 |
| 병원 | 약품, 억제제, (드물게) 완치제 | 높음 |
| 경찰서 | 탄약, 무기 | 높음 |

## 개발 원칙 (제안)

- **혼자 하는 플레이 먼저, 친구 접속은 나중에.** 모드 구분은 없지만, 개발은 혼자 4명을 운용하는 플레이를 완성한 뒤 친구 접속을 붙인다.
- **게임 상태는 하나의 데이터 구조로.** 저장과 멀티 동기화가 쉬워진다.
- **콘텐츠는 데이터로 분리.** 아이템, 지역, 이벤트, 직업, 특성은 JSON 같은 데이터 파일로 관리해서 코드 수정 없이 늘린다.
- **작게 시작.** 첫 버전은 직업 6개, 특성 12개, 지역 2개 정도로 시작한다.
- **아트와 사운드는 무료 에셋으로 시작해서 나중에 교체.**
