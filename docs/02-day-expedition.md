# 낮: 수색과 귀환

## 흐름 (확정)

1. 거점에서 **지역을 선택**한다.
2. 지역 안의 **출발 지점**에서 시작해 **약 10분** 동안 수색한다. 너무 짧으면 안 된다는 것이 기획 의도다.
3. 수색을 마치면 **출발 지점으로 돌아와야** 거점으로 귀환할 수 있다.
4. 제한 시간 안에 출발 지점으로 돌아오지 못하면, 아래 두 가지 중 하나를 고른다.

```
수색 (약 10분)
 ├─ 시간 안에 출발 지점 도착 → 정상 귀환 (대가 없음)
 └─ 시간 초과 → 선택
      ├─ 자동 귀환: 확실히 귀환. 대신 물자 손실, 부상, 감염 가능
      └─ 직접 귀환: 야간 전투를 하며 출발 지점까지 직접 이동
```

## 자동 귀환 (확정)

- 집으로 **반드시 돌아온다.**
- 대신 캐릭터 스탯에 따라 다음 대가를 치른다.
  - **전투 물자 소모**: 탄약, 무기 내구도 등을 쓰면서 돌아온다.
  - **미끼 사용**: 소지품 중 몇 개를 좀비 유인용으로 소비한다.
  - **분실**: 급하게 돌아오느라 아이템 몇 개를 잃어버린다.
- 어느 쪽이든 물자를 잃고 **다칠 수 있다.**
- **감염될 수도 있다.**

### 세부 규칙 (제안, 확인 필요)

기획자가 직접 고르는 방식을 추천한다. 시스템이 정하면 선택하는 재미가 없기 때문이다.

| 방식 | 대가 | 스탯 영향 | 사용 조건 |
|---|---|---|---|
| 돌파 | 탄약·무기 내구도 소모 | 전투 스킬이 높을수록 소모와 부상 확률이 줄어듦 | 무기나 탄약이 있어야 함 |
| 유인 | 미끼용 아이템 소비 | 은신 스킬이 높을수록 미끼가 적게 듦 | 미끼로 쓸 아이템이 있어야 함 |
| 질주 | 가방 속 아이템 일부 무작위 분실 | 체력과 이동 능력이 높을수록 분실이 줄어듦 | 항상 가능 |

- 선택 전에 예상 손실과 부상·감염 위험을 보여준다.
- 세 방식 모두 부상 확률과 감염도 상승 확률이 있다. 수치는 [감염](03-infection.md)과 밸런스 표에서 정한다.

## 직접 귀환 (확정)

- 밤이 된 지역에서 **직접 싸우면서** 출발 지점까지 이동한다.
- 늦어진 시간에 따라 결과가 달라진다.

| 늦어진 시간 | 결과 |
|---|---|
| 3분 이내 | 문제없음 |
| 3분 초과 ~ 5분 | 귀환은 하지만 **다음 날 아침에 외출 불가** (집에서 휴식) |
| 5분 초과 | **감염** |

- 직접 귀환 중 사망할 수 있는지, 5분 뒤에도 계속 버틸 수 있는지는 **미정** ([Q4](open-questions.md)).

## 시간 표시 (제안)

실제 1분을 게임 속 1시간으로 표시하면 규칙을 시계로 이해하기 쉽다.

| 실제 시간 | 게임 시각 | 의미 |
|---|---|---|
| 0분 | 08:00 | 수색 시작 |
| 10분 | 18:00 | 해 짐. 시간 초과 판정, 귀환 방식 선택 |
| +3분 | 21:00 | 이때까지 출발 지점 도착하면 무사 |
| +5분 | 23:00 | 이때까지 도착하면 다음 날 휴식. 넘기면 감염 |

## 수색 중 긴장 장치 (제안)

10분 동안 긴장이 유지되도록 다음 장치를 둔다.

- **소음 게이지**: 전투, 문 부수기, 뛰기로 올라가고, 높을수록 좀비가 더 많이 몰려온다.
- **가방 무게 제한**: 다 가져갈 수 없어서 무엇을 챙길지 고민하게 한다.
- **깊이에 따른 보상**: 출발 지점에서 멀고 깊은 곳일수록 좋은 물자가 있다. 대신 돌아오는 길이 멀다.
- **잠긴 문과 공구**: 공구가 있으면 더 많은 방을 열 수 있다.

## 모바일 고려 (제안)

- 수색 도중 전화나 앱 전환으로 끊겨도 **그 자리에서 이어지도록 자동 저장**한다.
- 앱이 백그라운드에 있는 동안에는 수색 시간이 흐르지 않는다.

## 미정

- 하루에 지역 1곳만 가는지, 여러 곳을 들를 수 있는지 (현재 설명 기준으로는 하루 1곳으로 보임. 확인 필요)
- 지역 맵을 매번 같은 구조로 할지, 무작위로 바꿀지
- 출발 지점이 지역마다 1곳인지, 여러 출구 중 고를 수 있는지
