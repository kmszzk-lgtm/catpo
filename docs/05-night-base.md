# 집: 거점과 협동

## 구조 (확정)

- **집(옥탑방)은 멀티플레이 장소이자 로비**이고, 항상 활성화되어 있다.
- **집 밖은 싱글플레이 장소**다. 집 앞 사거리에서 4방향으로 나가며, 한 방향에는 한 캐릭터만 나간다.
- 싱글플레이와 멀티플레이를 따로 구분하지 않는다. 캐릭터 4명이 항상 있고, 사람이 맡지 않은 캐릭터는 **AI가 활동**한다.
- 다른 사람이 들어오면 **비어 있는 캐릭터 중 하나를 골라** 플레이한다.
- 집 구조, 층별 캐릭터, 도르래, 시설 설치 방식은 [세계관과 게임 시작](00-world-and-start.md#거점-옥탑방-주택-확정) 참고.
  - 직접 돌아다니는 곳은 **옥탑방과 옥상뿐**이다. 아래층은 이미지로만 있고, 설비는 **아이콘을 터치해서** 넣고 조작한다 (**확정**).

## 집에서 하는 일 (제안)

물, 불과 요리, 텃밭, 바이오쿨러, 현관 보수, 지하실 봉쇄처럼 확정된 집안일은 [집안일과 생활](09-home-life.md)에 정리했다.

- 전리품 정리, 공용 창고 분배, 식량과 약품 배급
- 시설 설치와 제작 (함께 재료를 모아 설치)
- 도르래 업그레이드 (한 번에 올리고 내리는 무게·슬롯 증가, **확정**)
- 부상 치료, 휴식
- 스트레스 풀기: 화투·트럼프 카드로 함께 놀기(둘 이상), 취향에 맞는 제작 (**확정**, [스트레스](08-stress.md))
- 잠자기: 모두 잠자리에 들면 아침으로 넘어감. AI 캐릭터는 자라고 시켜야 함 (**확정**)
- AI 캐릭터 파견 (방향을 정해 보내기, **확정**)
- 서적 읽기 (레시피 배우기, 숙련도 부스트, **확정**. [제작과 서적](11-crafting-and-books.md))
- 분해해서 가져온 부품 결합 (**확정**)
- 현관 보수

캐릭터마다 집 안 활동의 효율이 다르다 (집냥이 보너스, 군냥이·의냥이 불이익). 자세히는 [캐릭터](04-characters.md#역할-정리).

## 습격 (확정)

- **밤에 주기적인 습격은 없다.**
- 처음에는 **1층 현관만** 막아 둔다. 바깥에서 계속 충격이 오므로 현관을 보수해야 하고, **현관이 뚫리면 게임 오버**다.
- 나중에 **봉쇄 이벤트**를 진행하면서 계단으로 올라오는 길을 가구, 나무, 돌 같은 온갖 것으로 막고, 방수포·테이프·비닐로 **계단과 통로를 아예 밀봉**한다 ([집안일과 생활](09-home-life.md#지하실-봉쇄-이벤트-확정)).

## 협동 규칙

| 항목 | 내용 | 상태 |
|---|---|---|
| 인원 | 캐릭터 4명 고정. 사람이 맡지 않은 캐릭터는 AI | **확정** |
| 들어오기 | 비어 있는 캐릭터 중 하나를 골라 플레이 | **확정** |
| 접속 방법 | 방 코드 또는 친구 초대 | 제안 |
| 시간 흐름 | 월드 시계는 모두가 공유. 모두 잠자리에 들면 아침으로 넘어감. AI 캐릭터는 자라고 시킨 뒤 넘어감 | **확정** |
| 연결 끊김 | 재접속 시 상태 복구. 끊긴 동안은 AI가 대신 활동 | 제안 |
| 결정 | 대부분 방장이 결정 | **확정** |
| 자원 공유 | 집에 오면 소지품이 **공용 창고에 자동 수납**. 나갈 때 창고에서 인벤토리로 꺼내 감. 밖에서는 인벤토리와 가방만 | **확정** |

## 저장 구조 (제안)

- 월드 데이터(집, 창고, 시설, 캐릭터 상태, 시계)는 **방장 기기 기준**으로 저장
- 친구끼리 하는 협동이라 데이터 조작 방지는 우선순위가 낮음

## 네트워크 기술 (제안)

- Unity: Photon Fusion, 또는 Netcode for GameObjects + Unity Relay
- 서버를 직접 운영하지 않는 방장 방식(P2P)으로 비용을 줄인다
- 집 밖은 싱글 공간이라, 외출 중에는 결과(획득 물자, 부상, 감염)만 집에 반영하면 된다

## 개발 순서 (제안)

1. 외출(수색, 전투, 귀환)을 먼저 완성
2. 집 파트를 혼자 하는 플레이로 구현 (AI 동료, 시설, 현관 보수, 봉쇄)
3. 친구 접속 추가 (상태 공유부터 시작)
