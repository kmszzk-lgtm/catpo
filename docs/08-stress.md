# 스트레스

## 쌓이는 경우 (확정)

| 상황 | 스트레스 |
|---|---|
| 자고 일어날 때마다 | 쌓인다 (기본) |
| 집 밖에 있을 때 | 집에 있을 때보다 **두 배**로 쌓인다 |
| 부상을 입었을 때 | 더 크게 쌓인다 |
| 동료가 죽었을 때 | **아주 많이** 쌓인다 |
| 취향에 안 맞는 제작을 할 때 | 쌓인다 |
| 의냥이가 집에 있을 때 | 가끔, 집에 있는 사람 중 **무작위 1명**에게 쌓인다 (태움) |

## 캐릭터별 (확정)

| 캐릭터 | 특성 | 효과 |
|---|---|---|
| 길냥이 | 불안 | 자고 일어날 때 **추가로 더** 쌓인다. 약 **두 배** |
| 의냥이 | 태움 | 의냥이가 집에 있으면 **가끔** 발동한다. **상시도, 매시간도 아니다.** 발동하면 집에 있는 사람 중 **무작위 1명**만 스트레스를 받는다. 의냥이가 **집 밖에 나가 있으면 생기지 않는다** |
| 군냥이 | 얼차려 | 스트레스 생성량 **-50%** |

- 군냥이는 얼차려(-50%) 덕분에 태움 영향이 거의 없다 (확정, 2026-11-08).
- 집냥이는 외출하지 않으므로 **태움의 주 대상**이다. 대신 집냥이는 **집에서 하는 모든 활동으로 스트레스가 풀려서** 알아서 해결된다 (확정, Q98).
- 태움은 집 안에 있어야 받는 것이니, **집 안에서 좋아하는 일을 하면서 풀면 된다** (확정, Q92).
- 오늘 외출했다 돌아온 사람은 대상이 아니다 (확정, Q98). 모두 자는 동안에는 생기지 않는다 (제안).

#### 태움 수치 (제안)

| 항목 | 값 |
|---|---|
| 발동 판정 | 의냥이가 집에 깨어 있는 1시간마다 15% |
| 1번 받는 스트레스 | 6 (군냥이는 3) |
| 하루 발동 횟수 | 깨어 있는 약 15시간 동안 평균 2번쯤 |
| 하루에 받는 양 | 집에 남은 사람이 둘이면 한 사람당 평균 약 7, 집냥이 혼자면 약 13 |

- 시간에 따른 스트레스(하루 6)와 기상(5)을 더하면, 집냥이는 하루 약 18~24 쌓인다. 집안 활동 1시간에 4씩 풀리므로(제안) 하루 5~6시간 집안일을 하면 버틸 수 있다.

## 푸는 방법 (확정)

| 방법 | 설명 |
|---|---|
| 고가치 아이템 | 동료가 고가치 아이템을 가져오면 풀린다 |
| 부족한 자원 | 집에 부족한 자원을 가져오면 풀린다. 예: 물이나 밥이 얼마 안 남았을 때 가져오기 |
| 취미 물건 | 화투, 트럼프 카드 같은 물건으로 논다. **둘 이상이 함께**해야 한다 |
| 취향에 맞는 제작 | 캐릭터 취향에 맞는 제작을 하면 풀린다 |
| 집냥이의 집안 활동 | 집냥이는 요리, 운동, 밭 관리 등 **집에서 하는 모든 활동**으로 풀린다 (생활력). 수치는 활동 1시간에 4 (제안) |

- **대화로 푸는 방식은 넣지 않는다.** 너무 쉬워지기 때문이다.

## 높을 때 효과 (확정)

- 식량 소모량이 늘어난다.
- 행동 속도가 느려진다.
- 제작 속도가 느려진다.
- 더 빨리 피로해진다.

## 제안 (확인 필요)

### 수치와 단계

| 스트레스 | 단계 | 효과 예시 |
|---|---|---|
| 0~39 | 보통 | 없음 |
| 40~69 | 예민 | 행동·제작 속도 -10%, 식량 소모 +10% |
| 70~99 | 한계 | 행동·제작 속도 -25%, 식량 소모 +25%, 피로 누적 +25% |
| 100 | 붕괴 | 하루 동안 아무 일도 하지 않으려 함 (이벤트) |

### 취향

캐릭터마다 좋아하는 제작과 싫어하는 제작을 둔다. 아래는 캐릭터 설정에서 떠올린 예시다.

- **길냥이는 집 안에서 좋아하는 제작이 없다** (확정, Q95). 길냥이는 집냥이가 아니다. 집 안에서는 함께 노는 취미로 푼다.

| 캐릭터 | 좋아하는 제작 | 싫어하는 제작 |
|---|---|---|
| 집냥이 | 요리 | **없음** (집에서 하는 모든 활동으로 풀림) |
| 군냥이 | 무기 손질 | 요리, 청소 같은 집안일 (부조리) |
| 의냥이 | 약 제조 | 집안일 (태움) |
| 길냥이 | **없음** (확정) | 오래 걸리는 큰 제작 |

### 취미 물건

- **프롤로그를 끝내면서 화투 1개, 트럼프 카드 1개가 생긴다** (확정, Q96).
- 혼자 할 때는 AI 캐릭터도 함께 노는 상대가 될 수 있다 (제안).
- 놀 때는 둘 이상이 모두 집에 있어야 한다. 1시간에 스트레스 8씩 풀린다 (제안).
- 첫 버전에서는 취미 물건이 닳지 않는다. 다른 취미 물건은 나중에 수색에서 얻는 것으로 검토 (제안).
