# 스트레스

## 쌓이는 경우 (확정)

| 상황 | 스트레스 |
|---|---|
| 자고 일어날 때마다 | 쌓인다 (기본) |
| 집 밖에 있을 때 | 집에 있을 때보다 **두 배**로 쌓인다 |
| 부상을 입었을 때 | 더 크게 쌓인다 |
| 동료가 죽었을 때 | **아주 많이** 쌓인다 |
| 취향에 안 맞는 제작을 할 때 | 쌓인다 |
| 의냥이가 집에 있을 때 | 외출하지 않고 집에 있는 사람에게 주기적으로 쌓인다 (태움) |

## 캐릭터별 (확정)

| 캐릭터 | 특성 | 효과 |
|---|---|---|
| 길냥이 | 불안 | 자고 일어날 때 **추가로 더** 쌓인다. 약 **두 배** |
| 의냥이 | 태움 | 의냥이가 집에 있으면, **외출하지 않은 사람**에게 주기적으로 스트레스를 준다. 의냥이가 **집 밖에 나가 있으면 생기지 않는다** |
| 군냥이 | 얼차려 | 스트레스 생성량 **-50%** |

- 집냥이는 외출하지 않으므로, 의냥이가 집에 있는 동안에는 늘 태움의 대상이 된다.
- 군냥이의 -50%가 모든 원인(기상, 태움, 부상 등)에 적용되는 것으로 이해했다 (제안, 확인 필요).

## 푸는 방법 (확정)

| 방법 | 설명 |
|---|---|
| 고가치 아이템 | 동료가 고가치 아이템을 가져오면 풀린다 |
| 부족한 자원 | 집에 부족한 자원을 가져오면 풀린다. 예: 물이나 밥이 얼마 안 남았을 때 가져오기 |
| 취미 물건 | 화투, 트럼프 카드 같은 물건으로 논다. **둘 이상이 함께**해야 한다 |
| 취향에 맞는 제작 | 캐릭터 취향에 맞는 제작을 하면 풀린다 |

- **대화로 푸는 방식은 넣지 않는다.** 너무 쉬워지기 때문이다.

## 높을 때 효과 (확정)

- 식량 소모량이 늘어난다.
- 행동 속도가 느려진다.
- 제작 속도가 느려진다.
- 더 빨리 피로해진다.

## 제안 (확인 필요)

### 수치와 단계

| 스트레스 | 단계 | 효과 예시 |
|---|---|---|
| 0~39 | 보통 | 없음 |
| 40~69 | 예민 | 행동·제작 속도 -10%, 식량 소모 +10% |
| 70~99 | 한계 | 행동·제작 속도 -25%, 식량 소모 +25%, 피로 누적 +25% |
| 100 | 붕괴 | 하루 동안 아무 일도 하지 않으려 함 (이벤트) |

### 취향

캐릭터마다 좋아하는 제작과 싫어하는 제작을 하나씩 둔다. 아래는 캐릭터 설정에서 떠올린 예시다.

| 캐릭터 | 좋아하는 제작 | 싫어하는 제작 |
|---|---|---|
| 집냥이 | 요리 | 무기 손질 |
| 군냥이 | 무기 손질 | 요리, 청소 같은 집안일 (부조리) |
| 의냥이 | 약 제조 | 집안일 (태움) |
| 길냥이 | 잠금장치·작은 도구 | 오래 걸리는 큰 제작 |

### 취미 물건

- 혼자 할 때는 AI 캐릭터도 함께 노는 상대가 될 수 있다.
- 취미 물건은 수색에서 얻고, 쓸수록 닳는다 (카드가 낡는 식).
