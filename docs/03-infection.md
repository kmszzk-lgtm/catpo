# 감염

## 감염 단계 (확정)

좀비 바이러스의 증상은 **고양이화**다 ([세계관](00-world-and-start.md)).

| 단계 | 상태 |
|---|---|
| 고양이 귀 | 플레이어 캐릭터의 기본 상태. 이미 감염됐지만 **안정된 초기 단계** |
| 감염 (발병) | 아래 규칙에서 말하는 "감염". 안정 상태가 무너져 변이가 진행되기 시작함 |
| 완전 변이 | 감염 후 10일. 고양이·호랑이 모습의 좀비가 되어 죽음 |

- 완치제는 발병한 캐릭터를 **고양이 귀 상태로 되돌린다.**

## 규칙 (확정)

- 감염되면 **10일** 뒤 **완전 변이**가 온다. 완전 변이하면 고양이·호랑이 모습의 좀비가 되어 죽는다.
- 치료제는 두 종류다.
  - **억제제**: 변이 진행을 늦춰 시간을 번다.
  - **완치제**: 고양이 귀 상태로 되돌린다.
- 캐릭터마다 자기 죽음을 알고 **스스로 집 밖으로 나가 죽는** 식의 마지막 선택 이벤트가 있다.

## 감염도 (확정)

- **집 안에서는 감염도가 오르지 않는다.** 의냥이가 집 안 정화 작업을 마쳤기 때문이다 ([집안일과 생활](09-home-life.md#현관과-정화-확정)).
- **집 밖에 나가 있는 동안 감염도가 오른다.**
- **밤이라서 더 오르는 것도, 해가 떠 있어서 덜 오르는 것도 아니다.** 바깥에 있던 시간만큼 오른다.
- 일정 시간(예: 10시간) 동안은 멀쩡하고, 그보다 오래 있으면 문제가 생긴다.
- 자동 귀환 중에도 감염될 수 있다.

### 밸런스 (제안, 기획자가 밸런스를 맡김)

그날 바깥에 있던 시간을 모두 더해서 판정한다. 하루에 여러 번 나가도 합산한다.

| 그날 바깥에 있던 시간 | 감염도 | 상태 | 결과 |
|---|---|---|---|
| 10시간 이하 | 0~83 | 안전 | 없음 |
| 10시간 초과 ~ 12시간 | 83~100 | 위험 | 귀환하면 **다음 날 외출 불가** (집에서 휴식) |
| 12시간 초과 | 100 | 발병 | **감염**. 10일 변이 카운트다운 시작 |

- 감염도는 바깥 1시간마다 약 8.3씩 오른다 (12시간에 100).
- 봄에 09:00에 나갔다면: **19:00**까지 돌아오면 안전, **21:00**까지 돌아오면 다음 날 휴식, 21:00을 넘기면 발병. 20:00은 휴식 구간 한가운데다.
- 감염도는 집에서 자고 일어나면 0으로 돌아간다 (의냥이의 정화). 이 부분은 확인 필요 ([Q43](open-questions.md)).

| 그 밖의 원인 | 감염도 | 비고 |
|---|---|---|
| 좀비에게 긁힘 | +8 (바깥 1시간 분량) | 수색 중에도 해당되는지는 [Q3](open-questions.md) |
| 좀비에게 물림 | +25 (바깥 3시간 분량) | |
| 자동 귀환 | 방식과 스탯에 따라 +8~25 | 확정 규칙("자동 귀환 중 감염 가능")을 게이지로 표현 |

- 물리고 긁힐수록 그날 안전하게 있을 수 있는 시간이 줄어든다.
- 특성 "높은 면역력"(제안)은 감염도 상승 속도를 늦춰 안전 시간을 늘린다.

### 계절과의 관계

| 계절 | 외출 가능 시간 | 감염도 기준 |
|---|---|---|
| 여름 | 12시간 | 끝까지 있으면 휴식 구간에 들어감. 해는 길어도 다 쓸 수 없음 |
| 봄·가을 | 9시간 | 해 지기 전에 오면 안전 |
| 겨울 | 6시간 | 감염도보다 짧은 해가 문제 |

## 변이 진행 (제안)

10일을 단계로 나누면 상태 변화가 눈에 보인다.

| 감염 후 | 단계 | 효과 예시 |
|---|---|---|
| 1~3일 | 잠복 | 겉으로 거의 티가 안 남. 피로가 조금 빨리 쌓임 |
| 4~7일 | 발열 | 최대 체력과 이동 속도 감소 |
| 8~10일 | 위독 | 큰 폭의 능력 감소. 마지막 선택 이벤트 발생 |
| 10일 | 완전 변이 | 좀비가 되어 사망 |

## 억제제와 완치제 (제안)

| | 억제제 | 완치제 |
|---|---|---|
| 효과 | 변이 카운트다운을 며칠 늦춤 (예: +2일) | 고양이 귀 상태로 되돌림 (**확정**) |
| 얻는 곳 | 병원, 약국 수색. 의냥이가 3층 의무실에서 제조 | 병원 깊은 곳, 연구소 같은 고위험 지역에서만 드물게 |
| 부작용 | 반복 사용 시 효과 감소 (검토) | 없음 |

얻는 방법과 수치는 **미정** ([Q5](open-questions.md)).

## 마지막 선택 이벤트 (제안)

캐릭터 4명이 고정이라, 캐릭터마다 고유한 마지막 행동을 만들 수 있다. 성격은 [캐릭터](04-characters.md)의 고유 특성에서 가져왔다.

| 캐릭터 | 마지막 행동 예시 |
|---|---|
| 군냥이 | 끝까지 계산적이다. 남은 시간 동안 가장 위험한 지역 수색을 자청하고, 돌아오지 않는다 |
| 의냥이 | 자기 몸을 마지막 연구 대상으로 삼아 기록을 남긴다. 완치제 제조 단서가 생긴다 |
| 길냥이 | 불안 때문에 감염을 숨긴다. 들키지 않으면 집 안에서 변이할 위험이 생긴다 |
| 집냥이 | 집냥이가 죽으면 월드가 끝나므로, 마지막 날 엔딩 장면으로 연결된다 |

플레이어가 막을 수 있는지(설득, 억제제 사용, 격리)도 선택지로 둘 수 있다.

## 미정

- 수색 중 물림·긁힘으로도 감염도가 오르는지 ([Q3](open-questions.md))
- 감염도가 집에서 줄어드는 방식 ([Q43](open-questions.md))
- 억제제 1회 효과와 얻는 방법, 완치제 희귀도
- 감염 사실을 다른 플레이어에게 보여줄지 숨길지 (협동 모드에서 긴장 요소가 될 수 있음)
