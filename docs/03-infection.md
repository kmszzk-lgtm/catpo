# 감염

## 규칙 (확정)

- 감염되면 **10일** 뒤 **완전 변이**가 온다. 완전 변이하면 좀비가 되어 죽는다.
- 치료제는 두 종류다.
  - **억제제**: 변이 진행을 늦춰 시간을 번다.
  - **완치제**: 감염을 완전히 치료한다.
- 감염 원인으로 확정된 것
  - 직접 귀환에서 **5분을 넘겨 복귀**
  - 자동 귀환 중 확률적으로 감염
- 캐릭터마다 자기 죽음을 알고 **스스로 집 밖으로 나가 죽는** 식의 마지막 선택 이벤트가 있다.

## 감염도 게이지 (제안, 확인 필요)

감염 원인을 하나의 게이지로 통일하는 방식을 추천한다.

- 감염도 0~100. 100이 되면 **감염 확정**, 10일 변이 카운트다운 시작
- 감염도를 올리는 것

| 원인 | 감염도 | 비고 |
|---|---|---|
| 좀비에게 긁힘 | +10~25 (확률) | 낮 수색 중에도 감염되는지는 [Q3](open-questions.md) |
| 좀비에게 물림 | +40~60 | |
| 자동 귀환 | 방식과 스탯에 따라 확률적으로 상승 | |
| 직접 귀환 5분 초과 | 즉시 100 | **확정** 규칙을 게이지로 표현한 것 |

- 감염 확정 전의 감염도는 응급처치나 소독으로 일부 낮출 수 있게 할지 정해야 한다.

## 변이 진행 (제안)

10일을 단계로 나누면 상태 변화가 눈에 보인다.

| 감염 후 | 단계 | 효과 예시 |
|---|---|---|
| 1~3일 | 잠복 | 겉으로 거의 티가 안 남. 피로가 조금 빨리 쌓임 |
| 4~7일 | 발열 | 최대 체력과 이동 속도 감소 |
| 8~10일 | 위독 | 큰 폭의 능력 감소. 마지막 선택 이벤트 발생 |
| 10일 | 완전 변이 | 좀비가 되어 사망 |

## 억제제와 완치제 (제안)

| | 억제제 | 완치제 |
|---|---|---|
| 효과 | 변이 카운트다운을 며칠 늦춤 (예: +2일) | 감염 완전 치료 |
| 얻는 곳 | 병원, 약국 수색. 약사 직업이 거점에서 제조 | 병원 깊은 곳, 연구소 같은 고위험 지역에서만 드물게 |
| 부작용 | 반복 사용 시 효과 감소 (검토) | 없음 |

얻는 방법과 수치는 **미정** ([Q5](open-questions.md)).

## 마지막 선택 이벤트 (제안)

성격(→ [캐릭터](04-characters.md#성격-제안))에 따라 마지막 행동이 달라지면 캐릭터에 애착이 생긴다.

| 성격 | 마지막 행동 예시 |
|---|---|
| 이타적 | 동료가 잠든 밤에 물자를 남기고 조용히 집을 떠난다 |
| 겁 많음 | 감염을 숨긴다. 들키지 않으면 거점 안에서 변이할 위험이 생긴다 |
| 냉정함 | 남은 시간 동안 가장 위험한 지역 수색을 자청한다 |
| 가족 걱정 | 가족을 찾아 떠나겠다며 거점을 나간다 |

플레이어가 막을 수 있는지(설득, 억제제 사용, 격리)도 선택지로 둘 수 있다.

## 미정

- 낮 수색 중 물림·긁힘으로도 감염되는지
- 억제제 1회 효과와 얻는 방법, 완치제 희귀도
- 감염 사실을 다른 플레이어에게 보여줄지 숨길지 (협동 모드에서 긴장 요소가 될 수 있음)
