# 오염과 감염

좀비 바이러스의 증상은 **고양이화**다 ([세계관](00-world-and-start.md)). 몸 상태는 **오염도**와 **감염도** 두 수치로 나눈다 (확정).

## 단계 (확정)

| 단계 | 상태 |
|---|---|
| 고양이 귀 (오염) | 플레이어 캐릭터의 기본 상태. 이미 바이러스를 지녔지만 **안정된 초기 단계**. 오염도 최저 1, 감염도 0 |
| 감염 | **좀비에게 물리거나**, **오염도가 50 이상**이 되면 감염 상태가 된다. 감염도가 날마다 오른다 |
| 완전 변이 | **감염도 100**. 이벤트가 일어나고, 고양이·호랑이 모습의 좀비가 되어 죽는다 |

- **오염과 감염은 따로 움직인다.** 감염 상태가 되어도 오염도는 그대로이고, 정화제로 계속 낮출 수 있다.
- **감염 상태는 완치제로만 없어진다.** 억제제로 감염도를 0까지 내려도 감염 상태는 치료되지 않는다. 정화제로 오염도를 50 아래로 낮춰도 감염 상태는 남는 것으로 이해했다.
- 처음 정한 "감염 후 10일 뒤 완전 변이"는, 감염도가 오르는 속도로 정해지는 방식으로 바뀌었다. 오염도 50에서 감염되면 약 10일이다.
- 캐릭터마다 자기 죽음을 알고 **스스로 집 밖으로 나가 죽는** 식의 마지막 선택 이벤트가 있다.

## 오염도 (확정)

- **최저 1**이다. 튜토리얼에서 의냥이가 시설 전체를 소독해서 모든 캐릭터가 1에서 시작한다. 1은 아무 일도 일어나지 않는 상태다.
- **집 안에서는 오르지 않는다.** 의냥이가 집 안 정화 작업을 마쳤기 때문이다 ([집안일과 생활](09-home-life.md#현관과-정화-확정)).
- **집 밖에 나가 있는 동안 오른다.** 밤이라서 더 오르는 것도, 해가 떠 있어서 덜 오르는 것도 아니다. 바깥에 있던 시간만큼 오른다.
- **50 이상이 되면 감염 상태로 바뀐다.** 감염 상태로 바뀐다고 오염도가 줄지는 않는다.
- **100이 되어도 죽지 않는다.** 대신 감염 상태일 때 감염도를 더 빨리 오르게 한다.
- 오염도가 몸에 주는 영향은 **스트레스뿐**이다 (확정). 오염도가 높을수록 스트레스를 더 많이 받는다.
- **지역 보스가 나타난 지역에서는 오염도가 하루 +5씩 추가로 오른다.** 튜토리얼에서는 플레이어가 모르지만 시스템으로는 오른다. 캐릭터들이 약해진 틈에 보스가 습격하는 구조다 ([엔딩과 거점 이전](13-endings-and-relocation.md#거대-호랑이-좀비냥-확정)). 집 안에서도 오르는 것으로 이해했다 (집냥이까지 약해져야 하므로).
- 오염도를 낮추는 것은 **의냥이가 만드는 정화제**다. 정화제는 오염도만 낮추고 감염도에는 듣지 않는다 ([정화제](09-home-life.md#정화제-확정)).
- **감염 상태에서도 정화제로 오염도를 낮출 수 있다.** 오염도가 낮아지면 감염도가 덜 빠르게 오른다.

### 밸런스 (제안, 기획자가 밸런스를 맡김)

| 항목 | 제안 |
|---|---|
| 바깥에서 오르는 양 | 1시간마다 약 4 |
| 하루 기준 | 1에서 출발하면 10시간 뒤 약 41, 12시간 뒤 약 49, 그 뒤 50에 닿음 |
| 다음 날 휴식 | 귀환할 때 오염도가 41을 넘었으면 다음 날 외출 불가 (확정 규칙 "늦게 돌아오면 다음 날 휴식"을 수치로 표현) |
| 좀비에게 긁힘 | 오염도 +4 (바깥 1시간 분량) |
| 자동 귀환 | 방식과 스탯에 따라 오염도 +4~12 |
| 정화제 1회 | 오염도 -20 정도. 의료 레벨이 높을수록 많이 낮춤 |

- 봄에 09:00에 나갔다면 **19:00**까지 오면 안전, **21:00**까지 오면 다음 날 휴식, 21:00을 넘기면 오염도 50에 닿아 감염된다.
- 정화제가 없어서 몸 정화를 못 하면 오염도가 다음 날까지 남는다. 그만큼 다음 외출에서 빨리 위험해진다.

## 감염도 (확정)

- **최저 0**이다.
- 감염 상태에서 날마다 오른다.
- **오염도 10마다 감염도가 하루 1씩 더 오른다.** 오염도 50이면 하루 +5, 100이면 하루 +10이 추가된다.
- 감염도는 정화제로 낮출 수 없다. **억제제와 완치제**만 감염도에 듣는다.
- **감염도가 높을수록 배고픔과 목마름이 더 빨리 오고, 스트레스도 더 많이 받는다** (확정).
- 행동 속도가 느려지는 것은 감염도가 아니라 **스트레스**가 높을 때다 (확정). 튜토리얼 끝에 캐릭터들이 약해지는 것도 오염도와 감염도로 스트레스가 쌓이기 때문이다. 스트레스 생성량이 절반인 군냥이가 비교적 멀쩡한 이유다.
- **감염도 100이면 완전 변이**하고, 이벤트가 일어난다.

### 상승 속도 (확정)

**하루 상승량 = 기본 5 + 오염도 10마다 1**

| 경우 | 하루 상승량 | 완전 변이까지 |
|---|---|---|
| 오염도 50에서 감염 | +10 | 약 10일 |
| 오염도 10에서 물림 | +6 | 약 17일 |
| 오염도 100 | +15 | 약 7일 |

- 감염된 뒤에도 정화제로 오염도를 낮추면 상승량이 줄어 시간을 벌 수 있다. 오염도 50에서 감염됐어도 오염도를 10까지 낮추면 하루 +6이 된다.

## 억제제와 완치제 (확정)

| | 억제제 | 완치제 |
|---|---|---|
| 감염도 | **10 낮춘다** | **감염 상태를 없앤다** |
| 그 밖의 효과 | **3일 동안 감염도가 오르지 않게 막는다.** 오염도가 높아도 막힌다 | 오염도가 10보다 높으면 **10까지 낮춘다** |
| 주의 | 감염도를 0까지 내려도 **감염 상태는 치료되지 않는다** | |

- 억제제 1개로 사흘을 버티고 감염도 10을 되돌린다. 기본 상승량(하루 5)만 따지면 억제제 1개가 약 5일을 벌어 준다.
- 완치제를 쓰면 오염도가 10이 되므로, 오염도 때문에 곧바로 다시 감염되지는 않는다. 처음 정할 때는 억제제가 열흘 동안 막는 것으로 했다가 3일로 바뀜.

### 제안

| | 억제제 | 완치제 |
|---|---|---|
| 얻는 곳 | 병원, 약국 수색. 의냥이가 3층 의무실에서 제조 | 병원 깊은 곳, 연구소 같은 고위험 지역에서만 드물게 |
| 부작용 | 반복 사용 시 효과 감소 (검토) | 없음 |

얻는 방법은 **미정** ([Q5](open-questions.md)).

## 감염도에 따른 외출 연출 (확정)

감염도가 높아질수록, 그 캐릭터로 외출하면 **해가 더 빨리 지는 것처럼** 보인다. 25 단위로 나뉜다.

| 감염도 | 화면 |
|---|---|
| 0~24 | 보통 |
| 25 이상 | 조금 덜 밝은 느낌 |
| 50 이상 | 어두운 느낌. 새벽과 저녁도 한밤중처럼 어둡고, 해가 중천일 때도 새벽이나 저녁 정도로 어둡다 |
| 75 이상 | 하루 종일 한밤중처럼 어둡다. 조명이나 광원을 아무리 밝혀도 광원 코앞만 밝고, 조금만 떨어져도 잘 안 보인다 |

- **화면 연출이다.** 좀비가 빨라지는 시간대(정오에 가장 느리고 자정에 가장 빠름)는 **실제 시각**을 따른다.

## 변이 진행 (제안)

감염도가 직접 주는 영향은 배고픔·목마름과 스트레스뿐이다 (확정). 아래 구간은 화면 연출(25 단위)에 맞춘 이름이다.

### 수치 (제안)

- 스트레스 생성 배율 = (1 + (오염도-1)/100) × (1 + 감염도/100). 오염도 1(기본)이면 1배, 51이면 1.5배. 감염도 100이면 2배.
- 배고픔·목마름 배율 = 1 + 감염도/100.

감염도 25 단위 연출에 맞춰 상태 변화도 같은 구간으로 나눈다.

| 감염도 | 단계 | 효과 예시 |
|---|---|---|
| 0~24 | 잠복 | 겉으로 거의 티가 안 남 |
| 25~49 | 미열 | 배고픔·목마름과 스트레스가 조금 더 빨리 쌓임 |
| 50~74 | 발열 | 배고픔·목마름과 스트레스가 눈에 띄게 빨리 쌓임 |
| 75~99 | 위독 | 배고픔·목마름과 스트레스가 크게 늘어남. 마지막 선택 이벤트 발생 |
| 100 | 완전 변이 | 좀비가 되어 사망 |

## 마지막 선택 이벤트 (제안)

캐릭터 4명이 고정이라, 캐릭터마다 고유한 마지막 행동을 만들 수 있다. 성격은 [캐릭터](04-characters.md)의 고유 특성에서 가져왔다.

| 캐릭터 | 마지막 행동 예시 |
|---|---|
| 군냥이 | 끝까지 계산적이다. 남은 시간 동안 가장 위험한 지역 수색을 자청하고, 돌아오지 않는다 |
| 의냥이 | 자기 몸을 마지막 연구 대상으로 삼아 기록을 남긴다. 완치제 제조 단서가 생긴다 |
| 길냥이 | 불안 때문에 감염을 숨긴다. 들키지 않으면 집 안에서 변이할 위험이 생긴다 |
| 집냥이 | 집냥이가 죽으면 월드가 끝나므로, 마지막 날 엔딩 장면으로 연결된다 |

플레이어가 막을 수 있는지(설득, 억제제 사용, 격리)도 선택지로 둘 수 있다.
