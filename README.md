# catpo

**좀비냥**: 좀비 아포칼립스 생존 모바일 게임 프로젝트 (Unity).

고양이화 바이러스가 퍼진 가상 도시 목성시. 고양이 귀가 달린 생존자 4명이 옥탑방 주택의 지하에서 버팁니다.
낮에는 각자 지역을 수색하고, 밤에는 거점에 모입니다. 귀환 시간과 감염 카운트다운이 긴장감을 만듭니다.

현재는 기획 단계입니다. 기획 문서는 [docs/](docs/README.md)에 있습니다.

> 루트의 `index.html`, `css/`, `js/`는 기획이 정해지기 전에 만든 웹게임 초안으로, 현재 기획과 관련이 없습니다. Unity 프로젝트를 시작할 때 삭제할 예정입니다.
